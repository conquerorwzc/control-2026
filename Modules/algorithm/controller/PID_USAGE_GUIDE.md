# PID 库使用指南

> 配套文档:本库 `README.md`(API 速查) + 可视化报告 `pid_report/index.html`(25 张图,自控经典展示方法)。
> 文中每个优化项标注了对应的可视化图,建议边看图边对照参数调。
> 旧接口完全兼容:不开启任何 `Improve` 标志时,行为与旧版一致。

---

## 0. 库总览

- 位置式/增量式 PID,全部优化通过 `config.Improve` 位标志组合(可用 `|` 叠加)。
- 核心 API:`PIDInit(pid, &cfg)` / `PIDCalculate(pid, measure, ref)` / `PIDCalculateEx(pid, m, r, ff)`(带前馈)。
- 辅助 API:`PIDSetGains`(在线调参,积分不变=无扰)、`PIDSetIntegral`(预置积分)、`PIDSetOutput`(无扰切换/跟踪)、`PIDSetSetpoint`(跳过斜坡)、`PIDReset`。
- 结构 API:`PID_Cascade_s`(串级)、`PID_SmithPredictor_s`(史密斯预估)、`PID_GainSchedule_s`(增益调度)。
- 整定工具:`pid_tuning.h`(Z-N / Cohen-Coon / SIMC / 4:1 衰减 / 继电自整定)。

## 1. 积分项优化:什么时候用

| 优化项 | 什么时候用 | 怎么开 | 注意 | 可视化图 |
|---|---|---|---|---|
| 1.1 梯形积分 | **默认推荐开启**;采样周期大、误差变化快时优势明显 | `PID_Trapezoid_Intergral` | 仅多一次加法/移位,嵌入式零成本 | 1.1 数值积分误差 |
| 1.2 积分分离(滞回) | 大偏差启动/大阶跃时防"积分蓄势"超调 | `PID_Integral_Separation` + `IntegralSeparationEnter/Exit` | Exit≤Enter 形成滞回;Exit 必须大于 P 环节稳态残差 1/(1+Kp),否则积分永不恢复 | 1.2 阶跃响应 |
| 1.3a 积分限幅 | 执行器会饱和(满占空/阀全开)时,最简单的抗饱和 | `PID_Integral_Limit` + `IntegralLimit` | 限幅过小会产生稳态误差,应 ≥ 稳态所需积分值 | 1.3 抗饱和 |
| 1.3b 条件积分 | 同上,饱和且误差仍加深饱和时冻结积分 | `PID_Conditional_Integral` | 依赖 `SatFlag`,需 `MaxOut` 与真实执行器限幅一致,否则不触发 | 1.3 抗饱和 |
| 1.3c 反计算抗饱和 | 要求退出饱和"干脆利落",快回卷 | `PID_BackCalculation` + `BackCalcGain` | `BackCalcGain=0` 自动取 Ki;**强烈建议显式给小增益(如 0.1)**,避免数值放大 | 1.3 抗饱和 |
| 1.3d 变速积分 | 误差大时积分慢、误差小时积分快,兼顾响应与超调 | `PID_ChangingIntegrationRate` + `CoefA/CoefB` | CoefA 是降速区宽度,CoefB 是全速区上界 | 1.4 阶跃响应 |
| 1.3e 积分先行 | 启动/切换前需要立即有输出(如重力补偿、云台启动) | `IntegralPreload`(初始化)或 `PIDSetIntegral()`(运行期) | 预载值≈稳态所需积分;过大会导致超调 | 1.5 阶跃响应 |
| 1.4 Kahan 求和 | 位置式长时间运行、Iout 大而 ΔI 小,防小量被"吃掉" | `PID_Kahan` | 仅位置式生效;增量式无需(输出即累积量) | 1.6 舍入误差 |

**组合建议**:1.1 梯形积分 + 1.3a 积分限幅(或 1.3c 反计算)是最常用的地基;1.2/1.3d 与抗饱和不冲突,可叠加;1.3e 用于启动场景。

## 2. 微分项优化:什么时候用

| 优化项 | 什么时候用 | 怎么开 | 注意 | 可视化图 |
|---|---|---|---|---|
| 2.1 微分先行 | **设定值频繁阶跃/快速变化的场景必开**(云台跟上位机角度、机器人路径跟踪) | `PID_Derivative_On_Measurement` | 微分只对测量值,设定值变化无冲击 | 2.1 时间响应 |
| 2.2 不完全微分 | 测量噪声大、微分放大高频噪声时 | `PID_DerivativeFilter` + `Derivative_LPF_RC` | 一阶惯性 Kd·s/(1+Tf·s);RC 越小带宽越高、滤波越弱 | 2.2 伯德图+噪声响应 |
| 2.3 四点差分 | 需要微分但两点差分噪声大 | `PID_FourPointDiff` | 隐式低通,对线性信号无相位偏移 | 2.3 频率响应 |
| 2.4 微分增益限幅 | 测量尖峰/毛刺经微分放大可打满输出 | `PID_DerivativeLimit` + `DerivativeLimit` | \|D\|≤Dmax 截断 | 2.4 时间响应 |
| 2.5 测量预处理 | 传感器噪声大(均值/中值/LPF),或需要滤脉冲 | `PID_MeasurementFilter` + `MeasureFilterMode(1均值/2中值)` + `MeasureFilterWindow` + `MeasureFilterRC` | **滤波相位滞后要计入整定**;窗口别开太大 | 2.5 时间响应 |

**组合建议**:2.1 + 2.2 是标准"微分先行+滤波";噪声特别大再叠加 2.3 或 2.4;2.5 属于测量侧,可与上述叠加,但延迟代价最大。

## 3. 控制结构优化:什么时候用

| 优化项 | 什么时候用 | 怎么开 | 注意 | 可视化图 |
|---|---|---|---|---|
| 3.1 增量式 PID | 电机/执行器控制,输出是增量累积;天然无积分饱和、无扰切换简单 | `PID_Incremental` | 输出为累积量并限幅;Iout 仅作观测 | 3.1 阶跃+饱和 |
| 3.2 2-DOF | 跟踪性能与抗扰性能需要独立调节时(快目标跟踪 vs 负载扰动) | `PID_2DOF` + `SetpointWeightP(b)` + `SetpointWeightD(c)` | b∈[0,1] 越小跟踪越不激进;抗扰几乎不变 | 3.2 阶跃+抗扰 |
| 3.3 前馈补偿 | 已知干扰/设定值变化(重力补偿、速度前馈、温度前馈) | `PID_Feedforward` + `pid.Feedforward`,或 `PIDCalculateEx(pid,m,r,ff)` | 前馈让 PID 只处理残差;静态前馈 u_ff=K·r | 3.3 阶跃响应 |
| 3.4 串级 PID | 多变量/快慢环(位置-速度-电流、温度-功率) | `PID_Cascade_s` + `PIDCascadeInit/Calculate` | 内环(快)先消扰动,外环(慢)更稳;内环采样频率应更高 | 3.4 抗扰阶跃 |
| 3.5 史密斯预估器 | 大纯滞后对象(管道运输、热传导) | `PID_SmithPredictor_s` + `PIDSmithInit/Calculate` | 需要较准的 FOPDT 模型,模型失配鲁棒性差 | 3.5 大滞后阶跃 |
| 3.6 增益调度 | 对象特性随工况变化(转速/温度/负载区间) | `PID_GainSchedule_s` + `PIDGainScheduleApply(pid,sched,x)` | 查表线性插值;积分项保持不变(无扰) | 3.6 分工况阶跃 |

**组合建议**:3.3 前馈可与一切叠加(收益大、风险小);3.2 2-DOF 与 3.3 常一起用于快目标跟踪;3.4 串级是"位置-速度-电流"标准做法;3.5/3.6 属复杂场景,系统复杂后再上。

## 4. 数字实现与工程细节:什么时候用

| 优化项 | 什么时候用 | 怎么开 | 注意 | 可视化图 |
|---|---|---|---|---|
| 4.1 dt 钳位 | 调度抖动/异常采样间隔时 | `DtMin` / `DtMax` | 内环采样频率应高于外环 | 4.1 采样间隔序列 |
| 4.2 输出软限幅 | 保护阀门/伺服等执行机构免受阶跃冲击 | `PID_SlewRateLimit` + `SlewRateLimit`(单位/s) | \|Δu\|≤Δu_max·dt | 4.2 时间响应 |
| 4.3 死区 | 抑制小幅误差引起的执行器频繁动作 | `DeadBand`(恒生效) | 位置式输出清零、增量式保持;会损失精度 | 4.3 时间响应 |
| 4.4 无扰切换 | 手动↔自动、控制器切换、模式切换 | `PIDSetOutput(pid, value)`(跟踪并反解积分)、`PIDSetIntegral`、`PIDSetGains`(保积分) | 切换瞬间输出连续无跳变 | 4.4 时间响应 |
| 4.5 设定值斜坡/滤波 | 需要柔化设定值阶跃 | `PID_SetpointRamp` + `SetpointRampRate`;`PID_SetpointFilter` + `SetpointFilterRC` | 快目标跟踪时慎用斜坡(人为滞后) | 4.5 阶跃响应 |
| 4.6 坏值检测/故障安全 | 传感器可能跳变/断线 | `PID_MeasureCheck` + `MeasureMin/Max`、`MeasureJumpLimit`、`MeasureErrorThreshold`、`FaultSafeOutput` | 坏值保持上一有效值;连续坏值输出安全值并置 `PID_MEASURE_FAULT_ERROR` | 4.6 时间响应 |

**组合建议**:4.4 无扰 + 4.6 故障安全是"可用性"底线,任何产品化控制建议开启;4.2 软限幅与 4.3 死区按执行机构特性选用。

## 5. 参数整定:什么时候用哪个

| 方法 | 函数 | 适用场景 | 特点 |
|---|---|---|---|
| Z-N 临界比例度法 | `PIDTuneZN_Oscillation(Ku,Tu)` | 一阶+滞后对象 | 经典,参数偏激进、超调大 |
| Z-N 响应曲线法 | `PIDTuneZN_ReactionCurve(K,L,T)` | 由阶跃响应建模 | 同上 |
| Cohen-Coon | `PIDTuneCohenCoon(K,L,T)` | 自衡对象 | 比 Z-N 温和,精度较高 |
| Lambda / SIMC | `PIDTuneSIMC(K,L,T,Tc)` | 化工过程/要鲁棒性 | Tc 直接设计闭环时间常数,鲁棒性好 |
| 4:1 衰减曲线法 | `PIDTuneDecayCurve(Kp_s,Tu_s)` | 一般过程 | 工程常用,比 Z-N 温和 |
| 继电反馈自整定 | `PIDRelayAutoTuneInit/Step/IsDone/GetKuTu/Tune` | 在线自整定 | 继电激励测 Ku/Tu,可自动接 Z-N |

**最常用组合**:继电反馈自整定(在线辨识 Ku/Tu)+ Z-N 初值 + SIMC 微调(调 Tc 增大相位裕度)。见可视化图 5.1(整定对比+相位裕度)与 5.2(继电限幅环→Ku/Tu→整定后阶跃)。

## 6. 场景组合配方(结合可视化报告)

### 配方 1:通用默认(几乎零成本,推荐默认)
```
Improve = 梯形积分 | 积分限幅 | 微分先行 | 不完全微分
```
适用:大多数位置/速度环。看图 1.1、1.3、2.1、2.2。

### 配方 2:云台/机器人快速目标跟踪(上位机给角度+速度前馈,输出力矩电流)
```
Improve = 梯形积分 | 积分限幅 | 微分先行 | 不完全微分 | 2-DOF | 前馈
+ 外环角度(慢)→内环角速度(快,用陀螺)串级(PID_Cascade_s)
+ 每周期 PIDCalculateEx(&pid, m, r, Kff*目标角速度)  # 速度前馈进内环
+ 需要加速度前馈时 u_ff += Ja*目标角加速度
```
要点:微分先行防设定值阶跃冲击;2-DOF b<1 压超调;前馈消除跟踪滞后;yaw 连续旋转注意 ±180° 角度归一化(在调 PID 前处理误差)。看图 2.1、3.2、3.3、3.4。

### 配方 3:电机速度环/输出累积型执行器
```
Improve = 梯形积分 | 增量式 | 微分先行 | 不完全微分 | 输出软限幅 | 无扰切换(切换时 PIDSetOutput)
```
增量式天然无积分饱和、无扰切换简单;软限幅保护执行机构。看图 3.1、4.2、4.4。

### 配方 4:大纯滞后对象(温控/管道)
```
Improve = 梯形积分 | 积分限幅 | 微分先行 | 不完全微分
+ PID_SmithPredictor_s(需较准 FOPDT 模型)
或 改用 SIMC 整定(Tc≥L)
```
看图 3.5、5.1。

### 配方 5:对象特性随工况变化
```
Improve = 梯形积分 | 积分限幅 | 微分先行 | 不完全微分
+ PID_GainSchedule_s:按工况量 x 查表(归一化环路增益)
```
看图 3.6。

### 配方 6:手自动切换/多控制器切换
```
Improve = 梯形积分 | 积分限幅 | 微分先行 | 不完全微分 | 坏值检测/故障安全
+ 切换瞬间 PIDSetOutput(pid, 当前手动输出)  # 反解积分,输出连续
```
看图 4.4、4.6。

## 7. 优先级建议(落地顺序)

1. **梯形积分 + 积分限幅/反计算抗饱和**(几乎零成本、收益最大)——图 1.1、1.3
2. **微分先行 + 微分滤波**(噪声场景必做)——图 2.1、2.2
3. **增量式 + 输出变化率限幅 + 无扰切换**(执行机构保护和维护友好)——图 3.1、4.2、4.4
4. **2-DOF 或前馈**(性能不够时再加)——图 3.2、3.3
5. **串级 / 史密斯 / 增益调度 / 自整定**(系统复杂后再上)——图 3.4、3.5、3.6、5.x

## 8. 常见误区 checklist

- [ ] `MaxOut` 是否与真实执行器限幅一致?(否则条件积分/反计算的 SatFlag 不触发,图 1.3 失效)
- [ ] 积分分离 Exit 是否大于 1/(1+Kp)?(否则积分永不恢复,图 1.2 失真)
- [ ] 反计算 `BackCalcGain` 是否显式设为小值?(默认取 Ki 可能数值放大)
- [ ] 开启测量滤波后,整定是否把相位滞后计入?(图 2.5)
- [ ] 快目标跟踪是否误开了设定值斜坡?(人为滞后)
- [ ] 微分先行是否已开?(设定值阶跃时的微分冲击,图 2.1)
- [ ] 增量式是否误把 Iout 当控制量用?(增量式下 Iout 仅观测)
- [ ] 切换模式前是否调用过 `PIDSetOutput`?(无扰,图 4.4)
- [ ] yaw 连续旋转时角度误差是否做了 ±180° 归一化?(库外处理)
