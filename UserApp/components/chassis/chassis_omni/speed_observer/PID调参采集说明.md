# 电机速度环、三轴速度外环和航向保持 PID 采集

2026-10-13：开始带载四电机共用参数整定。当前默认 `CHASSIS_VOFA_MODE=2`、`CHASSIS_TUNING_VOFA_VIEW=5`、`enable_speed_hold=0`，PID 采集串口 **460800、250 Hz（4 ms）**，无线端/PC 需同步设置。新增页 5 在同一帧回传四电机数据；下文页 0～4 的单电机/外环定义保留，115200/12 ms 属原版采集配置。四电机通道和激励设计以 [四电机带载整定方案](四电机带载整定方案.md) 为准。电机 PID 增益未变，未加入自动运动。

新增 `ChassisTuningVOFASend()`，保留 `ObserverVOFASend()` 噪声采集函数。两者均在 `ChassisTask()` 后通过原裁判串口 USART6 调用已有 VOFA JustFloat DMA 发送，按编译模式互斥。只回传一个代表电机，四个电机仍按原控制链同时工作、使用 `WHEEL_MOTOR_CONFIG` 中的一套初始 PID 参数。本次没有修改 Modules、BSP、串口波特率或各 PID 增益。

## 连接与选择

无线烧录器的数据透传串口连接底盘 USART6：PG14/TX → 烧录器 RX，PG9/RX → 烧录器 TX，GND 共地。本次只回传，不解析 PC 命令；仅采集时可不接板端 RX。VOFA 选择对应串口，当前 PID 模式 **460800、8N1、JustFloat**；原噪声模式仍为 115200。无线设备的透传端也需设为同样波特率。

`UserApp/robot/sentry_omni_chassis/robot_config.h`：

```c
#define CHASSIS_VOFA_MODE 2               // 0 正常裁判；1 噪声；2 PID 调参
#define CHASSIS_TUNING_VOFA_VIEW 5        // 0 单电机；1 vx；2 vy；3 wz；4 yaw_hold；5 四电机
#define CHASSIS_VOFA_MOTOR_ID 1           // 1 左前；2 左后；3 右后；4 右前
#define CHASSIS_TUNING_VOFA_BAUDRATE 460800u
#define CHASSIS_TUNING_VOFA_PERIOD_MS 4    // 当前 250 Hz；按实际波特率检查带宽
```

上面是单电机 PID 调参配置示例。当前配置为 **模式 2、页 5（四电机）**。模式 1、2 期间不注册裁判串口协议，裁判数据对象保持零值，导航 USART1 和 CAN 遥控继续工作。模式 0 恢复正常裁判通信；旧 `CHASSIS_NOISE_VOFA_PORT` 不再使用。

修改宏后重新编译烧录。调试器中也可修改全局变量 `chassis_tuning_vofa_view` 为 0～5 切页，无需重新烧录。切页只影响数据显示，不修改控制模式、使能或 PID 增益；页 5 通道定义独立，导出 CSV 时按通道 2 分组。

每帧 25 个 float32 加 4 字节帧尾，共 104 字节；460800 8N1 下耗时约 2.26 ms。当前 PID 模式 4 ms 一帧，占理论串口带宽约 56.4%；噪声页仍为原波特率的 20 ms/50 Hz。忙时跳过、不补发，并在写入 VOFA 的静态 DMA 缓冲前检查 TX 就绪。两种函数共用节流状态，只允许机器人任务按模式调用其中一种。

电机页记录的目标与反馈来自速度 PID 本次调用，避免把随后到达的 CAN 测速误当成此次计算的输入。辅助电流、温度和 CAN 间隔在短临界区内复制，是发送时最近的反馈，不保证与 PID 使用的那一帧 CAN 完全相同。底盘页目标已转换到底盘机体系，并包含当前角度环的叠加量：+x 朝电池、+y 向左、+wz 俯视逆时针。

电流指令和反馈采用驱动极性校正后的逻辑方向。通道 11 是待发的逻辑指令，不是 CAN 已成功发送的回执；CAN 打包还会进行反转和 int16 转换。当前速度环直接输出电流指令，应用没有启用自己的电流 PID；电调内部负责电流控制。按本项目已有 C620 换算，电流码值除以 819.2 可转换为 A，16000 约 19.53 A。

**不要把 Pout+Iout+Dout 当作始终等于实际输出。**现有 PID 在死区内将 Output 置零，但 P/I/D 字段可能保留历史值；输出滤波、限幅也会改变最终 Output。本次按实例真实字段回传，没有修改 Modules 中的 PID 行为。进入死区、未运行或清状态时，结合通道 10、11、17、22 判断。

三轴外环未启用、反馈无效或首次预置时，通道 4/5 仍显示当前目标与融合反馈；通道 6～10、18 来自 PID 状态，不能据此认为外环正在计算。航向页未运行时也显示当前航向目标与可读 INS 航向；INS 未就绪必须看状态 bit0。

## 状态位

通道 22 先转为无符号整数，再按位读取。bit0～14 沿用 [噪声采集状态定义](噪声标定采集说明.md)：bit0 为有效 INS 快照，bit7 为底盘关闭，bit12 为速度反馈可用，bit13 为速度外环已启用并预置，bit14 为本轮实际调用 yaw_hold_pid。

调参页额外增加：

| 位 | 含义 |
| --- | --- |
| 15 | 保留 |
| 16～18 | 当前底盘模式，`(status >> 16) & 7`：0 OFF、1 ROTATE、2 FOLLOW、3 HOLD |
| 19 | 代表电机当前 stop_flag 为使能；不等于反馈在线 |
| 20 | 代表电机在本轮观测器快照中在线 |
| 21 | 当前页 PID 在本周期实际执行了计算；三轴外环首次预置时为 0 |

电机 PID 在现有流程中即使底盘关闭也会计算，随后 CAN 停机逻辑将输出置零。因此电机页 bit21 可能为 1，但 bit19 为 0、通道 11 为 0。速度外环计算失败而回退时，bit21 可能为 1，但 bit13 为 0；实际输出以通道 11 为准。全部整数都小于 2^24，float32 可精确保存。

## 分阶段录制

### 1. 带负载整定共用电机速度环

本轮默认页 5，`chassis_init_config.enable_speed_hold = 0` 已配置，使三轴速度外环暂时不参与。遥控采用底盘机体系、不叠加跟随角度环的模式，整车带实际负载在地面低速运行。四个电机全部工作、同步记录，通道见四电机方案；若切页 0 则只记录所选代表电机。

共用参数修改 `WHEEL_MOTOR_CONFIG` 内的 `.speed_PID` 后重新烧录，四电机初始化时使用同一组参数。仅在调试器改一个电机实例的增益不会自动同步另外三个实例；需要统一修改四个实例或修改共用配置再烧录。

分别录制正反向的低速阶跃、小幅速度变化、匀速和回零，每个工况重复数次。优先比较通道 4/5 的跟随、超调、稳态误差和停稳时间；用 7～10 区分各 PID 分量和饱和，用 10/11 差异判断功率控制是否削减电流。电机升温明显时同时保留温度与相同负载说明。

当前采集率为 250 Hz，底层 PID 与 CAN 控制仍按原频率运行。它不能可靠评价几毫秒瞬态；若记录显示更快振荡，或上升时间内采样点不足，需要更高速记录，不能只靠这些曲线判断稳定。

### 2. vx、vy、wz 三个速度外环

电机速度环确定后，恢复 `.enable_speed_hold = 1`，确认状态 bit12、13 有效，再分别选页 1、2、3。每次以单轴目标为主，录制正方向、回零和负方向，保留完整 25 路。页面只决定观察哪一个环，三个外环的启用仍由共用开关控制；若要单独关闭某轴修正，可将该轴 Kp/Ki/Kd 设为 0，其余控制结构不变。

比较 4/5 的目标跟随与稳态误差；通道 10 是 PID 修正，不含前馈，通道 11 才是逆解实际使用的速度。对照 19 的轮速正解和 EKF，检查滤波延迟；wz 页再用 20 的 gyro_z 对照。记录中保留 21 的代表电机电流指令、23 的功率限额，避免把执行能力不足误判为外环增益不足。

### 3. yaw_hold 航向角环

页 4 已支持回传 `yaw_hold_pid`，但本次没有自动开启它。当前 `chassis_init_config` 未配置 `enable_yaw_hold` 和其增益，初始化值为 0；现有遥控分支也不会进入 `CHASSIS_HOLD`。因此只切到页 4，并不会让机器人开始航向保持，bit14/21 应为 0。

以后启用时，需要配置 `enable_yaw_hold=1`、航向 PID 参数，并由控制入口持续选择 `CHASSIS_HOLD` 和设置 `yaw_hold_ref`。目标必须与 `INS.YawTotalAngle` 使用同一个连续角度基准，不能直接混用 [-180,180] 的单圈角度。当前遥控命令每周期会重写模式，不能只在调试器修改一次 chassis_mode 后认为能持续进入 HOLD。

整定顺序为电机速度环 → wz 速度外环 → yaw_hold 航向角环。角环输入是度，输出是 rad/s；航向 PID 的 MaxOut 限制的是其角速度贡献。页 4 的通道 10、19、11 分别表示角环输出、叠加后的角速度目标、经速度外环后的最终角速度命令，可以用于判断串级响应。

## 发回数据

导出完整 25 路 CSV，保留 PC 时间列和 seq/time_s/view/status。建议文件名：`motor_loaded_pos.csv`、`motor_loaded_neg.csv`、`vx_hold.csv`、`vy_hold.csv`、`wz_hold.csv`、`yaw_hold.csv`，每次更换增益另存文件；注明负载、地面、代表电机 ID、外环开关和控制模式。未启用的 yaw_hold 不需要录制阶跃，只会得到观测数据而不是闭环响应。

此功能只发送观测数据，不接收串口在线调参命令，不自动执行阶跃，不调整增益，也不修改 Q/R。
