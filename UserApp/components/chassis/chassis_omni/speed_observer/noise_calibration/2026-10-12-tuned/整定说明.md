# 首轮实机日志整定：平动 vx/vy、转动 wz 优先

用户确认转动时机械/云台偏心会带动车体产生真实平移，本轮按真实运动处理。**保持加速度预测启用，不扣除转动同步分量，不将整段运动加速度的方差当作随机噪声。** 用户要求优先保证仅平动时 vx/vy、仅转动时 wz；本次分别使用相应片段确定参数，耦合运动不作为首要优化目标。

本次已将下表写入 `UserApp/robot/sentry_omni_chassis/robot_config.h`。属于有日志依据的首轮有效 Q/R 整定，尚不能等同于独立真值验证后的绝对速度精度标定。

## 1. 已应用的参数

| 参数 | 原值 | 本次值 | 主要依据 |
| --- | --- | --- | --- |
| process_noise | {0.5, 0.5, 1.0} | **{0.025, 0.035, 1.5}** | 平动过程一致性的稳健估计；转动起停的角速度变化 |
| wheel_variance | {0.01, 0.01, 0.04} | **{0.0007, 0.0005, 0.015}** | 平动短窗口测速残差；原地转动轮速与 gyro 的有效差异 |
| gyro_variance | 0.0004 | **0.0002** | 两轮静止段 gyro_z 方差及余量 |
| accel_variance | {0.25, 0.25} | **{0.04, 0.0002}** | 匹配低通后的平稳静止输入方差及余量 |
| initial_variance | {0.25, 0.25, 0.25} | 保留 | CSV 不足以识别启动先验；不影响稳态结论 |
| max_dt / sensor_timeout | 0.05 / 0.02 s | 保留 | 采样有效性限制，不作为噪声参数调节 |

以上都是方差或噪声密度，不是标准差。速度观测 R 单位为 (m/s)²、(rad/s)²，加速度输入方差为 (m/s²)²，过程项按 `q*dt` 进入协方差。

IMU 安装方向、133.5 mm 杆臂、轮径/减速比/安装半径保持已有实测配置。电机、速度外环、yaw_hold 的 PID 未整定：本轮是速度观测器参数整定，当前噪声 CSV 没有完整的目标值/控制输出，不能据此宣称完成 PID 整定。没有修改 Modules 层。

## 2. 使用哪些数据

- `静止.csv`：7564 点，提供包含机构振动的稳定 gyro 与 y 加速度基线。
- `平动.csv`：2877 点，按 vx 或 vy 主导分别选段；主轴速度 >0.15 m/s，且大于另一轴绝对速度的 3 倍。
- `转动（包括顺逆时针）.csv`：2005 点，提供原地正反转角速度的一致性与起停变化。
- `new.csv`：2444 点，提供改进后输入的起始停转基线和原地转动数据。

只用有限、输入资格满足要求的快照，跳过跨采集跳号的辨识窗口。没有将停转后的真实恢复过程与起始稳定停转混成一个静止噪声组。

旧平动日志的 center_ax 来自改进前的直接差分，不能作为新版噪声基线。本轮只为平动过程一致性计算，用原始 IMU 点加速度、gyro 和实际 CSV 时间在 50 Hz 近似重建匹配补偿；没有拿旧 center_ax 的 4.17 方差继续配置新版。

## 3. 测量噪声如何得到

### 陀螺仪和加速度

旧完整静止 gyro_z 方差约 1.5835e-4，新起始停转段约 1.8548e-4。取较大值乘 1.05，并向上取整到 1e-4，得到 **2e-4**。不额外扣除这次短记录中的均值，启动零偏标定仍由现有驱动完成。

新匹配补偿后的起始停转共有 92 点，center_ax/ay 方差约 **0.035601 / 0.00017206**。加入约 10% 余量并向上取整，得到 **0.04 / 0.0002**。x 噪声仍大于 y，因为 x 包含滤波角加速度的杆臂项。

该静止基线较短，因此使用保守余量；它是当前新版输入的随机噪声近似，不代表覆盖温度、所有机械状态的完整标定。

### 平动轮速

在各主轴平动的连续 9 点窗口内，用实际时间拟合三次局部多项式。局部平滑的真实速度变化由多项式表示，以中心点拟合残差估计短时有效测速不确定度，并按拟合杠杆值修正方差缩减：

```text
residual = measured_center - local_cubic_prediction
corrected_residual = residual / sqrt(1-h_center)
Rwheel = 1.2 * var(corrected_residual)，再向上取整
```

最终为 **vx 0.0007、vy 0.0005**。该方法仅用于离线参数辨识，运行时没有增加多项式滤波或删除真实速度变化。

局部真实快速运动、轮速不同步和已有滤波仍可能影响这个有效 R；它不是严格分离出的编码器白噪声。静止近零量化值没有被用来将 R 设为零。

### 转动轮速

使用稳定原地转动段，以已有启动零偏校正的 gyro_z 作为角速度参考。两份记录稳定转动样本的 `wheel_wz-gyro_z` 二阶矩约为 **0.01090、0.01258 (rad/s)²**。合并后扣除 gyro 的随机方差、加 20% 余量并取整，得到 **0.015**。

这是含轮速尺度差、不同步、滑移及 gyro 参考误差的有效不确定度，不是单独电机随机噪声。约 2% 的尺度差异没有被擅自写成新的轮径或安装半径。角速度融合因此仍主要依赖 gyro，避免被这项差异明显拉偏。

## 4. 过程噪声如何得到

### vx、vy

保留实际加速度与机体系转动项，按连续 CSV 间隔计算：

```text
dvx/dt = center_ax + gyro_z*wheel_vy
dvy/dt = center_ay - gyro_z*wheel_vx

e = wheel_velocity_next - wheel_velocity_now
    - 0.5*(model_derivative_next + model_derivative_now)*delta_time
```

`e` 表示在现有测量和模型下的间隔不一致，不等于真实运动本身。辨识使用 x/y 主导平动各 **286 / 327** 个连续间隔。

少数 20 ms 间隔出现接近 1 m/s 的轮速变化，会支配二阶矩。若直接取所有 e² 的平均，得到 q_x≈0.603、q_y≈0.396。无法只凭日志判定这些事件来自真实冲击、轮速瞬态、不同步还是模型误差；因此本轮采用 **e² 在 95% 分位处限幅的稳健辨识统计**，防止少数事件决定整段固定 Q：

```text
q_eff = mean((min(e², percentile95(e²)) - 2*Rwheel
              - 0.5*Raccel*delta_time²) / delta_time)
```

得到 q_x≈**0.02054**、q_y≈**0.03167**，加余量取整为 **0.025 / 0.035**。正负方向分别检查，x 约为 0.0141/0.0266，y 约为 0.0272/0.0369，采用共同参数折中。

**95% 限幅只发生在离线辨识统计中。没有限幅、删除或扣除运行时的实际加速度、周期运动、轮速样本，也没有给融合增加异常值拒绝门限。** 固定基线 Q 的这种选择是工程整定，并非唯一统计解；强烈冲击的效果仍需实机复采确认。

降低 q_xy 与降低 Rwheel 同时进行。以 1 kHz、单轴近似为例，原轮速校正增益约 0.20，新 vx 约 0.17、vy 约 0.23：不会因为 R 降低就将融合简单变成轮速直通，IMU 对真实短时速度变化的预测仍保留。

### wz

当前 wz 预测是随机游走，没有将角加速度用作 wz 预测输入。因此真实转动起停的角速度变化必须进入过程项，而非 gyro 测量噪声。

在原地转动有效连续间隔上计算 `mean((delta_gyro_z²-2*Rgyro)/delta_time)`，两份数据得到约 **1.557 / 1.394**，合并取整得到 **1.5**。这一项不按平动的稳健规则截去起停变化，优先保证真实角速度变化的跟随。

相较旧参数，wz 会更跟随 gyro。静止 wz 曲线未必更平滑，但高速正反转时对轮速约 2% 差异的依赖较小。此处遵循“速度准确和跟随优先”的目标，而不是只追求视觉平滑。

## 5. 真实机械运动保留

用户确认的机械/云台偏心导致的平移，不再作为本轮需要消除的残差处理。加速度预测继续启用，计算路径仍为：

```text
INS 去重力加速度
  -> 匹配低通后的固定 IMU 杆臂补偿
  -> 真实中心加速度
  -> 含机体系转动项的 vx/vy 预测
  -> 轮速和 gyro 观测校正
```

没有拟合并减掉转动谐波，也没有将运动时约 1.9 m/s² 的幅值直接填成加速度随机噪声。历史分析中“周期残差尚需区分原因”的表述已由用户的实机确认补充；本轮按真实运动保留。

## 6. 验证与精度边界

参数直接写入正式机器人配置，新增宿主测试从该配置提取参数，并与离线产物逐项核对。测试编译正式 `speed_observer.c`，在 1 kHz 下覆盖正负纯 vx、纯 vy、正反转 wz，以及带超过 2 m/s² 真实加速度的耦合运动，加入已知传感器噪声和约 2% 轮速角速度尺度差。

合成测试 vx/vy RMSE 约 **0.008 m/s**，wz 约 **0.0125～0.0127 rad/s**，有限性与真实加速度预测检查通过。这是已知真值的模拟回归结果，**不能当作实车精度指标**。原有融合、协方差、杆臂匹配、速度外环和 VOFA 测试一并通过。

已用现有 CMake 编译命令重新编译受影响 STM32 源文件、完成 ELF 链接并生成 HEX/BIN。存在既有多行注释、未使用变量/函数警告；未烧录本轮参数、未测量改动后的实车速度误差。

现有 CSV 是 50 Hz 快照，缺少完整 1 kHz 历史和独立绝对速度参考。因此：

- Q 是基于间隔一致性、参考测量和稳健选择的有效整定，不宣称唯一最优。
- R 暂按对角阵，未新增轮速相关噪声、动态滑移自适应或加速度偏置状态。
- 绝对 vx/vy 尺度仍受实际轮径、减速比、滑移影响；wz 尺度仍需独立角度参考才能最终验证。
- 后续优先复采单独前后、左右、顺逆转动，保留同样机构状态；耦合运动只检查可用性。若有定距计时或定位真值，可进一步验证精度和调整参数。
