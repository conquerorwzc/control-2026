# 四电机带载速度环：共用参数整定

日期：2026-10-13。目标是四个电机使用同一组 Kp/Ki/Kd，在真实装车负载下兼顾前后、左右和正反旋转。以所有电机稳定、最差响应可接受为约束，再改善平均跟随效果；不能承诺不依赖工况的唯一“最优 PID”。

## 本轮已准备的代码

- 用户确认无线透传最高 1 Mbps，测试区域前后左右约 5 m，可带载正反旋转。USART6 PID 采集设为 460800、8N1、VOFA JustFloat，模式 2、页 5、4 ms 一帧（250 Hz）。无线透传和 PC 均需设相同波特率。
- 四电机同一控制周期的数据按 CAN ID1、2、3、4 排列。原单电机页 0 和外环页 1～4 保留。
- 暂时关闭三轴速度外环；观测器继续运行。共用电机参数仍是 Kp=4、Ki=0、Kd=0，MaxOut=16000，IntegralLimit=8000。
- 功率限制仍为当前 120 W，不关闭保护。需结合实际电流指令辨别功率削减。
- 没有加入自动激励、没有在线改增益命令、没有烧录或启动机器人。本文件中的波形是待执行实验设计。
- 没有修改 Modules、BSP、硬件初始化文件或电机 CAN 发送周期。只在应用启动、USART6 尚未注册 DMA 时，为 PID 模式重新配置波特率；正常裁判/噪声模式仍沿用原硬件波特率。

## 四电机页的 25 路定义

| 通道 | 内容 |
| --- | --- |
| 0 | seq，采集时隙序号，跳号表示漏采/漏传 |
| 1 | time_s，本轮底盘控制采样时间，秒 |
| 2 | view，固定为 5 |
| 3 | 四个速度 PID 的最大 dt，秒；不是串口采样间隔 |
| 4 | status，转整数后解码 |
| 5～9 | ID1：Ref、Measure、PID.Output、applied、反馈电流 |
| 10～14 | ID2：同上 |
| 15～19 | ID3：同上 |
| 20～24 | ID4：同上 |

Ref/Measure 是电机转子轴 deg/s，来自正式速度 PID 当轮保存的输入。输出和电流均为逻辑方向的协议码值；applied 是功率控制后的待发送指令，停机报告 0，不是 CAN 发送成功回执。反馈电流是快照时最新值，不保证与 PID 所用测速来自同一 CAN 帧。四路装在同一遥测帧，不代表编码器硬件同步采样。

status bit0～14 沿用噪声页，其中在线位 bit8/9/10/11 按内部数组顺序 ID1/4/2/3 排列；新增 bit16/17/18/19 分别为 ID1/2/3/4 使能，bit20 为速度外环 active（本轮应为 0），bit21 表示至少一个使能电机的 PID 输出与功率限制后指令相差超过 1 码值，bit22 表示至少一个 PID 达到自身输出限幅。整数字段低于 2^24，可由 float32 精确保存。

温度、P/I/D 分量和完整参数仍可在原单电机页 0 检查。本页为维持 25 路上限不重复发送；每次试验应记录共用增益、限幅、负载、地面与试验前后温度。不要在同一份无标注 CSV 中途修改增益。

460800 下每帧 104 字节，250 Hz 占 260 kbit/s，即约 56.4%；每帧线缆发送约 2.26 ms，发送时隙为 4 ms。采集端按实际串口波特率检查至少 20% 线路余量，当前实际余量约 43.6%。无线空口、缓存和重传仍可能丢帧，结合 seq 与 time_s 判断。250 Hz 仍不能可靠判断几毫秒振荡；若响应时间内有效样本不足，应升级记录方案。控制器实际按约 1 ms 调用，CAN 指令约 2 ms 发送，不能把 4 ms 遥测间隔当作控制器周期。

## 激励通过合法底盘运动生成

整车四轮接地且带实际负载。不单独让一个轮子在车体不动时执行阶跃；其他轮子约束会形成额外拖拽，结果不能直接代表正常运动。

采用底盘机体系命令，经已有逆运动学得到四轮目标。三轴外环、跟随角度环和 yaw_hold 均不参与。现遥控右拨杆上/中采用 CHASSIS_ROTATE，拨轮居中时可做平动；不要用会叠加跟随控制的模式。命令生成器若后续实现，应默认不运行，需操作者持续使能，先生成命令再经过原急停检查；离线/急停后终止，不能自动恢复试验。

| 单轴正方向 | 目标分量 | ID1/ID2/ID3/ID4 逻辑轮速符号 |
| --- | --- | --- |
| 前进 | vx>0，vy=wz=0 | - / - / + / + |
| 左移 | vy>0，vx=wz=0 | + / - / - / + |
| 逆时针旋转 | wz>0，vx=vy=0 | + / + / + / + |

反向命令取反，覆盖四个电机的正反向及不同轮载。仅测原地转动不能代表平动负载。

## 分阶段波形

幅值为试验初案，需按场地和首轮响应决定，不能跳过小幅测试直接运行全幅。每个测试单独触发、结束回零，前后/左右位移近似抵消不等于机器人能严格回到原位置。

### A：静止基线与小幅起停

先记录 3～5 s 使能零目标基线。用 vx=±0.20 m/s、vy=±0.20 m/s、wz=±0.50 rad/s 分别确认采集、跟随和刹停；这只是短暂的开场检查，不作为实际工况整定的主要数据。

```text
0（1 s）→ +A（0.5～0.8 s）→ 0（0.8～1 s）
        → -A（0.5～0.8 s）→ 0（0.8～1 s）
```

各工况重复 3 次；回零后若未稳定，不继续下一段。先分清启动延迟、静摩擦、正反差异、功率限幅与刹停，不直接高速正反切换。平台持续时间覆盖整定时间；若响应慢，延长时间前需核对允许位移。

### B：分级阶跃与运动中小阶跃

用户确认实际平动范围 1～2 m/s、角速度范围 3～6 rad/s。主测试平动 A=1.00/1.50/2.00 m/s，旋转 A=3.00/4.50/6.00 rad/s，重复正/反/回零。主测试覆盖实际工作范围，低速仅作为开场检查。

平动采用以下单向短序列，X/Y 和正/反分别执行，段间回零等待稳定并核对位置：

```text
0 → 1.0 m/s（0.25 s）→ 1.5（0.25 s）→ 2.0（0.40 s）→ 1.0（0.30 s）→ 0
```

单方向指令位移积分约 1.725 m，不含停稳余程；按测试区域总宽 5 m 保守留出边界余量。若需要延长稳态段，改为一个短段单独运行，不能把所有平台一起延长。每段结束观察实际停稳及位置，反向指令积分抵消不能保证车体回到起点。

旋转测试分为 `0→+3→0→-3→0`，然后 ±4.5、±6 rad/s，每个非零平台初案 1～1.5 s，回零 1 s 或直到稳定；稳定后补充 `3→4.5→6→4.5→3→0` 的同向动态。遇到持续限功率要区分执行能力与控制器跟随，不能靠增加增益让不可达目标变可达。

电机首轮采集时遥控拨轮最高档约 ±4.90 rad/s；当前遥控已改为直接生成 ±1.5 和 ±5 rad/s 两档目标，平移单轴满杆 2 m/s。6 rad/s 仍需后续应用层测试命令入口，不能靠拨轮打满覆盖；现有导航 wz 也不参与转向。专门入口尚未实现，本轮固件没有自动激励。

主测试同时包含实际非零工作点附近的速度阶跃，例如 1.00→1.20→1.00 m/s、1.70→2.00→1.70 m/s，以及旋转 3.0→3.6→3.0、5.4→6.0→5.4 rad/s（反向亦然）。每段平动控制总指令位移并留出刹停余程。它们帮助区分起步摩擦与滚动动态。从零大幅跳速时四轮 PID/120 W 功率限幅可能主导响应，因此分别评估实际起步能力和未饱和的小扰动动态，不能只根据大阶跃上升时间选增益。

### C：小幅多级激励（首轮数据决定是否需要）

在实际常用的非零基准速度附近叠加固定种子的有界多级序列，初案幅值为基准的 10%～20%，保持时间 0.10/0.20/0.40 s。旋转单段可取 4～6 s；平动按速度限制单段时长，初案最多 1～1.5 s，预计位移不超过 2 m，必要时进一步缩短。每段末尾回零，停稳并核对位置后单独触发反向，分开记录 X、Y、旋转与正反方向。仅在阶跃响应稳定、采样率足以覆盖目标动态后执行。

该阶段用于补充不同变化快慢下的响应，不将单次速度目标阶跃当作电流到速度的开环阶跃。四电机相互耦合，独立单输入模型只能作为指定运动工况的局部近似。若明显耦合，需联合模型或直接比较多工况闭环表现。

### D：共用参数验证

用未用于选参的阶跃顺序、另一组幅值及更长稳速段检查四电机正反响应。完成单轴验证后做正常使用范围的组合运动验证；不会用极低幅值实验保证最高速度下的效果。

## 如何综合得到一组参数

1. 首轮保持现有 Kp=4，Ki=Kd=0，采集四电机基线。识别输入取功率限制后的 applied，输出取 Measure；速度目标用来评价跟随。保留真实时间和跳号。
2. 将持续功率削减/电流饱和段与未饱和动态分开；前者仍用于能力与饱和恢复验证，不用于直接推导线性增益。轮离线、停机、不完整采样等片段不参加动态拟合。
3. 对各电机、正反方向和 X/Y/旋转分别计算归一化积分绝对误差、超调、整定时间、稳态偏差、电流峰值/均方值、饱和时间及电流抖动；归一化尺度采用阶跃幅值，避免低速指标失真。
4. 先调整统一 Kp，在四电机都不出现持续振荡的范围内提高跟随；再增加统一 Ki 修正带载稳态误差，验证回零和功率削减后的积分恢复。默认优先 PI，只有数据证明需要阻尼改善且采样足够时再考虑带滤波 D。
5. 共用参数可按“最差工况损失 + 平均损失 + 电流代价”筛选，并对所有工况设置稳定性/饱和约束。不是四份最优增益的算术平均。候选模型评估后仍需少量实车试验迭代，最终结论限定于已测试负载、速度和地面。

实验设计参考：[MathWorks：无模型时的 PID 整定](https://www.mathworks.com/company/technical-articles/tuning-a-pid-controller-when-a-plant-model-is-not-available.html)、[用于辨识的输入输出数据](https://www.mathworks.com/help/control/getstart/io-data-for-identification.html)。闭环采集必须区分目标输入与执行器实际输入，不能将已有闭环响应直接当作开环对象响应。

## 导出数据

完整导出 25 路 CSV，文件名例如 `motor4_loaded_kp4_ki0_kd0_vx.csv`，Y 和旋转分别保存。注明负载、地面、共用参数、功率上限、透传波特率、外环关闭、试验前后温度；保留起步前和停稳后的记录。若本轮不改增益，三类单轴数据足以开始第一轮比较，但不足以直接宣布最终最优参数。
