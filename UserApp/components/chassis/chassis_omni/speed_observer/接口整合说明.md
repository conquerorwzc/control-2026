# 运动学与速度观测器接口整合

2026-10-13。本次仅整合运动学正解和速度卡尔曼观测器，不延续已经撤回的全应用代码整理。

## 使用方式

底盘中只保留一个观测实例：

```c
SpeedObserver_s speed_observer;
```

初始化调用一次 `SpeedObserverInit()`，几何参数使用 m；现有机器人配置仍使用 mm，由 `ChassisInit()` 按原来的倍率转换。Q/R、融合开关、IMU 安装偏移和超时值继续来自原配置，没有调整数值。

周期内准备一份 `SpeedObserverInput_s` 传感器快照，只调用：

```c
SpeedObserverUpdate(&chassis->speed_observer, &input, dt);
```

更新内部完成四轮正解、样本去重及超时处理、IMU 杆臂补偿、卡尔曼预测/校正和超长时间间隔重置。底盘的 `EstimateSpeed()` 仅复制快照并同步原采集状态，不再自行解算或调用多个观测器函数。

对外读取两组速度，都是 `Speed_s { vx, vy, wz }`：

```c
chassis->speed_observer.wheel; // 四轮运动学速度
chassis->speed_observer.fused; // 卡尔曼融合速度
```

单位为 m/s、m/s、rad/s，机体系 +x 向前、+y 向左、+wz 俯视逆时针。不增加 IMU 独立积分速度输出；IMU 只作为融合输入，原有原始数据采集快照继续保留。

- `updated`：本周期融合或重置成功；可以是只预测成功。
- `valid`：本周期结果可用于原速度外环，要求时间步长合理、结果有限且轮速没有离线或超时。
- `status`：原采集状态位；底盘关闭和闭环标记仍由原底盘逻辑补充。

模型、协方差、杆臂及采样历史为实例内部状态，由初始化/更新函数维护，不是新的对外速度结果。逆运动学仍供原输出控制使用，与正解共用 `speed_observer.model`。

## 本次具体变化

| 修改前 | 修改后 |
|---|---|
| 独立 `omni_kinematics.h` | 数学实现合入 `speed_observer.c/h`，不再保留单独运动学文件；底盘外不需单独调用正解 |
| `OmniVelocity` | 简化为统一速度类型 `Speed_s` |
| `chassis->kinematics` | `chassis->speed_observer.model` |
| `chassis->measured_velocity` | `chassis->speed_observer.wheel` |
| `chassis->estimated_velocity` / `speed_observer.velocity` | `chassis->speed_observer.fused`，去掉重复结果存储 |
| `chassis->observer_updated` | `chassis->speed_observer.updated` |
| `chassis->speed_feedback_valid` | `chassis->speed_observer.valid` |
| chassis 文件内的采样历史静态变量 | 移入对应观测器实例，多个实例历史互不干扰 |
| 公开 Reset、杆臂更新和中心加速度辅助函数 | 收为内部实现，更新调用方不再依赖这些函数 |

`chassis.c/h` 只做相关接入和字段访问调整；VOFA 只同步读取位置，不改通道或发送逻辑。初始化配置增加专用 `SpeedObserver_Init_Config_s`，传入原 Q/R、几何与传感器条件；原 `robot_config.h` 无需修改。

机器人目录（含 `RobotInstance`、导航、裁判和遥控实例）、原有功率控制、航向控制、模式与急停逻辑、Modules/Bsp/Hardware 均不在本次修改范围。原先未使用的函数和实例仍保留。资料没有搬迁，也未批量格式化原底盘或机器人文件。
