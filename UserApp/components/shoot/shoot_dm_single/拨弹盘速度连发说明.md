# 单发、连发与自动退弹

适用sentry_gimbal、DM-J4310、输出轴与十二齿拨弹盘1:1直连。当前实现只修改UserApp：shoot_dm_single的shoot.c/shoot.h和遥控模式映射；Modules、Bsp、Hardware及摩擦轮控制逻辑不变。

## 外部发射模式

| 模式 | 值 | 行为 |
| --- | --- | --- |
| LOAD_STOP | 0 | 立即停止拨弹输出，复位卡弹状态并恢复临时修改的参数 |
| LOAD_1_BULLET | 1 | 位置双环按周期逐颗拨弹，每次累计角度目标增加30° |
| LOAD_BURSTFIRE | 2 | 速度PI连续拨弹，带实际齿相位阻力力矩前馈 |

删除LOAD_STEP及LOAD_REVERSE，不保留手动退弹入口或手动完成状态。新单发承接原STEP行为，保持命令会按周期连续逐颗拨弹，不再只响应模式进入。

单发进入后立即拨第一颗。之后必须同时满足“前一颗角度到位”和“距上次启动达到周期”才增加下一颗目标；不到位不累计目标，不补赶错过的节拍。增量基于原位置目标，不基于到位容差内的实际角度，避免齿相位逐次漂移。

单发到位容差沿用0.03 rad；load_period_ms表示调度周期，单发和连发命令均须明确指定正周期，不再提供默认周期回退。停止命令不使用周期。动作耗时长于周期时，实际弹频取决于到位时间。

遥控保持：左下关闭、左中只开摩擦轮、左上拨弹；左上时拨轮小于−100选700 ms单发，大于100选50 ms连发，回中保持档位。离开左上恢复慢档选择。未增加退弹遥控绑定。

## 控制参数与前馈

| 项目 | 单发 | 连发 | 自动退弹 |
| --- | --- | --- | --- |
| 外环 | 累计角度位置环 | 速度环 | 累计角度位置环 |
| 位置Kp | 18 | 不使用 | 18 |
| 速度PI | 0.6 / 0.1 / 0 | 0.16 / 0.3 / 0 | 0.6 / 0.1 / 0 |
| 位置环输出上限 | 6 rad/s | 不使用 | 4 rad/s |
| 速度PI输出上限 | 7 N·m | 7 N·m | 3 N·m |
| 积分上限 | 5 N·m | 2 N·m | 5 N·m |
| 力矩前馈 | 推进段锚点曲线0.9～3.8 | 2.1～3.7 N·m（单谐波） | 0 |

单发推进段（位置目标未到位）叠加相位力矩前馈，到位或超调后清零；速度前馈机制已整体删除（含驱动配置标志）。前馈函数按模式切换两条曲线：单发曲线为分段的准静态锚点设计（静持0.4、爬行过限位2.5～2.7、硬突破4～5实测锚点：基线0.9、+3°~13°升至3.8、13°~17°平台、17°~26°回落至0.9，均值约2.4），连发维持稳态辨识的单谐波。1103/1108验证确认if切换与前馈贴合（全bin偏差RMS 0.03 N·m），突破区13°~17°零卡弹；据两轮数据将下降段由17°~23°延至17°~26°：φ18°~22°为弹链落座区，移动负载实测2.6~3.5 N·m（静态仅0.4），原尾部0.9~2.0不足，曾致19%~56%的发在末段2°~4°爬行触发自动退弹。单发另立曲线的依据：单发推进样本方程误差跨文件交叉验证失败（0.68内 vs 2.08跨），说明单发负载随速度体制变化（静态/移动两态），无法辨识为单一相位曲线。叠加方式：驱动层双环PID链结果（final_output）加前馈后统一限幅至±速度环MaxOut，直接发送力矩，与连发出口一致。

单发位置Kp由12调为18，位置环输出上限由15降至6 rad/s，增强中小误差纠偏并限制起步速度；正向速度参考上界即6 rad/s。退弹共用位置Kp=18，但仍临时采用4 rad/s、3 N·m限幅；速度PI及其他参数保持原值。

连发保留60 rad/s²速度参考斜坡；20 Hz目标约10.472 rad/s，25 Hz约13.090 rad/s。PI与阻力前馈相加后，应用层总输出仍统一限制到±speed_PID.MaxOut，默认±7 N·m。不加加速度力矩前馈。

连发补偿按实际累计角度减接触角取30°周期，相对接触角φ的曲线为：

| 相位 | 力矩前馈 |
| --- | --- |
| 全周期 | τ_ff(φ) = 2.9 + 0.8·cos((φ−9°)·2π/30°)，φ为齿相位 |

前馈为单一余弦谐波：峰值3.7 N·m位于+9°，低谷2.1 N·m位于+24°，均值2.9 N·m。曲线来自五轮CSV的方程误差灰箱辨识（J·dω/dt+Bω+g(ψ)+b(z)=τact，执行器一阶惯性T≈3ms）：周期负载只需1阶谐波（2、3阶验证无改善），峰位跨轮10.2°±1.2°；前三次迭代使用的分段smoothstep平台位置（[+5,+11]→[+13,+19]）分别基于旧拟合和准稳态反推，后者存在系统性峰位后移偏差，已废弃。均值2.9对应当前弹链（111/222，阻力比前三轮高约0.5 N·m）辨识需求3.0，留−0.1由积分吸收。接触角沿用robot_config.h当前配置，未重新标定。

辨识同时确认：B呈负值（闭环混淆，不可单独解释）、J跨轮漂移3.5倍（不可信），故不据此调整PID，PI维持0.16/0.3。PID、卡弹检测和退弹参数本次均不变。新曲线仍需实机采样验证。

## 共用自动退弹状态机

LoaderJam(speed, now)统一管理单发、连发的检测、回退及恢复。speed为正常拨弹的目标平均角速度，返回1表示已接管本周期电机输出，返回0才执行正常单发/连发。不再通过特殊参数复位；停止和外部模式切换沿用LoaderMode，自动复位内部状态。

| 内部状态loader_state | 值 | 动作及转移 |
| --- | --- | --- |
| LOADER_NORMAL | 0 | 检查本模式是否满足受阻条件；首个合格采样进入CHECK |
| LOADER_CHECK | 1 | 统计80 ms窗口和角度极值，仍继续正常拨弹；条件中断回NORMAL，确认受阻进入BACK |
| LOADER_BACK | 2 | 追踪本次固定反向目标；到位或超时后恢复原模式并回NORMAL |

不增加等待、恢复、手动完成或失败状态，不设置重试计数和次数上限。状态在shoot.c内部定义，不新增公共配置或ShootInstance成员。CHECK明确表示窗口有效，去掉FLT_MAX哨兵、窗口有效性隐式判断及旧jammed标志。

检测条件：

| 项目 | 单发 | 连发 |
| --- | --- | --- |
| 检测启用 | 原位置目标−实际角度大于到位容差 | 当前速度参考≥最终速度目标的50% |
| 实际速度绝对值 | <min(1 rad/s，30°/周期×20%) | <1 rad/s |
| 实测正向力矩 | ≥1.5 N·m | ≥1.5 N·m |
| 候选角度最大值−最小值 | ≤3° | ≤3° |
| 连续满足时间 | 80 ms | 80 ms |

默认700 ms单发的低速阈值约0.150 rad/s，避免把正常慢速移动直接按连发1 rad/s阈值判断。单发到位等待和超调后的反向纠正不启用检测。单发阈值尚待带载实测。

进入CHECK时记录当前时间并将最大/最小角度设为当前位置，保证从首个合格采样计时。条件中断回NORMAL；角度范围超过3°时，留在CHECK并从当前位置重建窗口。首次建窗或重建窗口后立即返回，不对同一采样重复更新极值及检查时长。确认期间继续原正常控制，不提前停止或退弹。

## 回退与恢复

进入BACK时只执行一次：

1. 暂存原位置目标，用于单发恢复。
2. 切换到原位置双环，清两个PID和力矩前馈。
3. 锁定回退目标为确认时实际累计角度−18°，记录开始时间。
4. 临时限制位置环输出±4 rad/s、速度环输出±3 N·m。

进入依据状态转换，不再根据“当前外环是否ANGLE_LOOP”判断，保证单发位置环也能正确进入回退。后续追踪同一目标，不逐周期累加退角。

角度误差绝对值<3°，或本次回退经过180 ms，即结束；不检查速度。18°是参考退角，误差窗口和机械惯性使实际退角可能不同。

结束时通过LoaderMode恢复原模式参数、清PID及前馈并重置last_load_tick：

- 单发：恢复此前未完成的位置目标，完成同一颗；恢复当周期不追加30°，从恢复时刻重新计算下一颗的调度周期；单发力矩前馈仍为0。
- 连发：清PID后从实际速度重建速度参考，同周期执行原连发控制，恢复原力矩前馈，不累计回退期间的斜坡时间。

没有额外等待，再受阻就再次检测回退。外部停止、联动关闭、电机离线或无有效反馈均从统一入口取消。外部单发/连发模式切换取消旧动作，从当前实际位置进入新模式；同一模式只改变周期不会取消回退，完成后按最新周期恢复。

## 函数与状态归属

- LoaderMode：集中复位内部动作状态、选择正常单发/连发PID和外环、恢复正常限幅、清PID和前馈、重建参考与时间戳。
- LoaderJam：NORMAL/CHECK/BACK状态机，包括固定回退目标、回退输出、完成判断和恢复；删除独立LoaderBack，避免只有少量动作的额外封装。
- LoaderControl：原有统一入口、模式进入、状态机调用和正常发射分流，末尾只更新一次last_load_mode。目标平均角速度只计算一次，供卡弹检测、连发斜坡和单发速度前馈共用。
- LoaderStop、LoaderBurst、LoaderFeedforward继续承担停止、速度连发、相位曲线计算。

last_load_mode记录上一次外部命令，不作为内部退弹状态。last_load_tick按阶段复用为单发启动、连发斜坡或回退开始时间；检测窗口保留独立开始时间。均按无符号毫秒差处理时钟回绕，无阻塞延时。

保留原有统一的停止/联动、在线和rx_len检查；周期直接取命令值，当前遥控每次选择单发或连发时均明确赋值700 ms或50 ms。删除默认周期配置和回退逻辑，不增加零周期检查；停止命令在角速度计算前返回。不重新添加非法枚举范围、固定齿角正值、遥控空指针等此前未授权新增或已删除的检查。本次遥控器原有检查不变。

## 结构体与观测

Shoot_Ctrl_Cmd_s保留命令周期load_period_ms，Shoot_Init_Config_s删除默认周期loader_period_ms，Load_Mode_e只保留三个值。ShootInstance继续引用长期有效的config，不复制固定参数。

- 实际角度：shoot->loader_motor->measure.total_angle
- 原位置目标/回退目标：shoot->loader_motor->motor_controller.pid_ref
- 连发速度参考：shoot->loader_motor->motor_controller.speed_PID.Ref
- 力矩前馈：shoot->loader_torque_feedforward
- 内部动作状态：shoot.c静态变量loader_state，0正常、1确认、2回退

单发同样采用ANGLE_LOOP，不能仅用outer_loop_type区分单发正常推进和退弹。八通道验证可采集角度、速度、pid_ref、speed_PID.Ref、力矩前馈、最终输出、反馈力矩及loader_state；需要调积分时可用Iout替换目标或速度参考通道。

## 验证与实机边界

- 真实shoot.c与controller.c配合电机/时间桩，21组测试在-O2、-Ofast下通过。覆盖周期单发、无目标积压与相位漂移、单发等待/超调不检测、阈值/80 ms/3°窗口、固定退角、单发原目标恢复、同周期恢复不多发、180 ms超时、20/25 Hz恢复、停止/离线/模式切换取消、连续自动重试及时间戳回绕；包含CHECK期间停止或切换模式后的自动复位、重新计时，以及位置Kp18/限幅6下的启动、受阻推进和超调纠偏验证。
- 使用原data4.csv作20 Hz检测监测回放，三组受阻首次触发为10.549080、16.754014、23.675666 s，保留的17.25 s正常窗口无触发。回放不模拟真实退弹后的机械变化，不证明退弹成功率或新的单发阈值有效性。
- 测试脚本：cmake-build-debug/loader-speed-host/run_auto_jam_tests.py（忽略目录）。
- STM32F4/sentry_gimbal Release编译链接通过，生成ELF、HEX、BIN；仍有既有bsp_log.h多行注释警告。验证构建目录沿用先前的生成Ninja注释换行修正，根CMake未改。
- 未烧录、未实机测试。下一步带载采集重点为700 ms单发经过限位时的误判情况、实际退角、180 ms回退能力和原目标恢复，再验证20 Hz连发。
