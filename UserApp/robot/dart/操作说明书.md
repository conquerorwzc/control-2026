# 飞镖发射架操作说明书

适用固件：`UserApp/robot/dart/`（分支 `feat/dart-launcher`）
控制器：STM32F407 单板，遥控器 DR16（DBUS / huart3）
机构：yaw（M2006）+ 同步带 ×2（M3508）+ 扳机丝杆（M3508）+ 扳机舵机（270° PWM 舵机）

---

## ⚠ 安全须知（务必先读）

1. **侧边拨轮已损坏弃用**，不要拨它；原拨轮功能全部移到**右摇杆竖直**。
2. **上电前确认已卸压**：发射平台没有被扳机锁住、拉簧处于放松状态。上电使能会自动做零位校准，丝杆和同步带都会**低速顶机械限位**；若平台带压，校准移动扳机可能**意外发射**。
3. **急停：右开关拨到下档**，任何时刻都立即断全部电机输出。遥控器离线同样自动停机。
4. 发射（左开关拨上）只在“已储能/就绪”状态有效，其他状态拨了不会射——但**不要把上档当试探档**，就绪后拨上就是真发射。
5. 校准/储能过程中人不要在发射平台活动范围内；同步带储能时挡块会向后拉约一圈电机轴。
6. 所有行程参数（储能行程、射力范围、舵机卡位/释放角）都是**占位值或半标定值**，实机必须重新标定（见第七章），未标定前小行程试跑。

---

## 一、上电前检查清单

- [ ] 发射平台已卸压（拉簧放松、平台未被扳机卡住）
- [ ] 飞镖未上弦，或明确准备发射
- [ ] 发射架周围无人，炮口/发射方向安全
- [ ] 遥控器已开机并连接（右侧小开关不在下档前先确认连接）
- [ ] 右开关置于**下档**（安全位）再上电
- [ ] 首次上电/换线后：先走“第三章 首次调试”，不要直接走正常流程

---

## 二、遥控器映射总表

| 输入 | 正常档（右开关**中**） | 调试档（右开关**上**） |
|---|---|---|
| **右开关** | 下=急停 / **中=使能**（首次使能自动校准） | **上=使能 + 调试点动**（**不**自动校准） |
| **左开关** | 下=待机；**下→中=储能**（故障/未校准时=重新校准）；**中→上=发射** | 同左（校准/储能/发射命令照常有效） |
| **右摇杆水平** | yaw（瞄准），满杆 60°/s | 同左 |
| **右摇杆竖直** | **射力调节**（扳机丝杆位置），仅待机/就绪时生效 | **舵机角度**：下满 0°、中位 135°、上满 270°（标定卡位角/释放角用） |
| **左摇杆竖直** | — | **同步带双电机同速点动**，满杆 60°/s（正向=储能方向） |
| **左摇杆水平** | — | **扳机丝杆点动**，满杆 60°/s |

要点：
- 左开关的命令都是**拨动瞬间触发**（上升沿），停在某个档位不重复触发。
- 射力调节是**保持摇杆**持续调：上推=射力增大，下推=减小，范围 10°~90°（相对丝杆零点）。
- yaw 任何使能状态都可用（校准/储能中也能瞄）。

## 三、首次调试流程（换线、换电机、首次上电必做）

1. 右开关**上档**上电 → 进调试档，**不会**自动校准，机构保持静止。
2. **验方向**（点动，动作都是小幅的）：
   - 左摇杆竖直轻推：两个同步带电机应同向转动，**正向（推上）应是储能方向**（把挡块往“拉平台”的方向带）。方向反了 → 改 `robot_config.h` 的 `DART_BELT_L_REVERSE` / `DART_BELT_R_REVERSE`（两个一起改）。
   - 左摇杆水平轻推：丝杆应转动；确认**哪个方向是“射力增大”**。反了 → 改 `DART_SCREW_REVERSE`。
   - 右摇杆水平：yaw 转向确认。反了 → 改 `DART_YAW_REVERSE` 或取反摇杆映射。
3. **扫舵机找角度**（右摇杆竖直缓慢扫全程，观察扳机）：
   - 记下“**扣住发射平台**”的角度 → 填 `DART_SERVO_CATCH_DEG`；
   - 记下“**释放**”的角度 → 填 `DART_SERVO_RELEASE_DEG`；
   - 两者必须明显分开；`DART_SERVO_RELEASE_DEG` 应使扳机完全脱开。
   - 现在默认值：卡位 135°、释放 0°、行程 0~270°（270° 舵机，0.5~2.5ms）。
4. 确认丝杆**零点方向**：`DART_SCREW_CALI_DIRECTION` 决定校准时朝哪头顶限位。判据：顶到的那端必须是“**射力最小**”的一端（零点=最小射力）。反了改 ±1。
5. 烧写含以上标定值的固件，右开关拨**中档**，左开关**下→中**一次 → 开始自动校准。
6. 校准完成（日志 `calibration done (belt + screw)`）后先小射力、短行程试射一次。

## 四、正常工作流程（一发）

### 1. 校准（每次上电一次，自动执行）
右开关拨到**中档**使能后自动开始（若校准失败或中断，左开关**下→中**重来）。顺序与预期动作：

| 步骤 | 机构动作 | 速度 |
|---|---|---|
| ① 同步带找零点 | 两电机朝释放方向低速顶硬限位 | 8°/s（严格限流） |
| ② 同步带回撤 | 退 15° 到“释放位置”（挡块让开发射平台） | 20°/s |
| ③ 丝杆找零点 | 朝“最小射力端”低速顶硬限位 | 8°/s（严格限流） |
| ④ 丝杆就位 | 退开并走到**默认射力位置**（30°） | ≤300°/s |

日志依次出现：`start zero calibration (belt + screw)` → `belt zero found...` → `belt zero done, start screw zero calibration` → `screw zero found...` → `calibration done (belt + screw)`。
全程约十几秒（取决于上电位置到限位的距离）。

### 2. 调射力（可选，随时）
**右摇杆竖直**上推=射力增大 / 下推=减小，范围 10°~90°。就绪（READY）后仍可调——**调完需重新储能**才对这一发生效。

### 3. 储能
**左开关 下→中**。自动执行：
1. 丝杆走到射力位置（必须先就位）；
2. 同步带把发射平台**向后拉指定行程**（平台滑过单向扳机，不会堵转），约 3 秒；
3. 同步带**限速退回到释放位置**，挡块退出平台活动范围，约 3 秒。

完成后日志 `charged, ready to fire`，进入**就绪**。全程约 6~7 秒。

### 4. 发射
**左开关 中→上**。扳机舵机转到释放角 → 释放平台、飞镖弹出（约 1.1 秒内完成）→ 舵机自动回卡位角，状态回待机。

### 5. 连发（第 2、3、4 发）
每发都是重复 2→3→4：**调射力（可跳过）→ 左开关下→中（储能）→ 左开关中→上（发射）**。
发射后**必须重新储能**才能打下一发（没有自动连发）。4 发打完停在待机即可，右开关拨下档收工。

## 五、运行状态与日志对照

没有屏幕，状态靠 RTT 日志（Ozone / J-Link RTT Viewer）识别：

| 状态 | 含义 | 特征日志 / 现象 |
|---|---|---|
| 待机 IDLE | 可调射力、可储能 | 无动作，舵机保持卡位角 |
| 校准 CALIBRATING | 上电自动，或手动重校 | `start zero calibration (belt + screw)` |
| 储能 CHARGING | 左开关触发 | `charge sequence start` → `charge stroke done, reset to release position` |
| 就绪 READY | **可发射**，平台已上弦 | `charged, ready to fire` |
| 发射 FIRING | 左开关上触发 | `fire sequence start` → `fire sequence done, back to idle` |
| 故障 FAULT | 全部停机，需人工处理 | `fault: ...`（见下表） |

命令被忽略时会打 `charge/fire/calibrate command ignored`（例如未就绪时拨发射）。

## 六、故障与恢复

### 故障日志对照

| 日志 | 原因 | 处理 |
|---|---|---|
| `fault: belt calibration stall timeout` | 同步带 8 秒内没顶到限位：方向反了 / 上电位置离限位太远 | 查 `DART_BELT_CALI_DIRECTION`；或调大 `DART_BELT_CALI_TIMEOUT_MS`、提高 `DART_BELT_CALI_SPEED_DPS` |
| `fault: screw calibration stall timeout` | 丝杆同上 | 查 `DART_SCREW_CALI_DIRECTION` / 超时 |
| `fault: belt/screw calibration backoff timeout` | 回撤卡住或目标不可达 | 检查机械卡滞 |
| `fault: screw not in position before charge` | 储能前丝杆 2 秒没走到射力位置 | 查丝杆机械/行程宏 `DART_SCREW_POS_*` |
| `fault: belt stalled during charge` | **储能行程超过滑台行程**或机械卡滞 | 把 `DART_BELT_CHARGE_DEG` 调小（须小于滑台行程对应角度） |
| `fault: charge timeout` | 5 秒没拉到目标位置 | 同上，查行程/机构 |
| `fault: retract timeout` | 同步带 5 秒没退回释放位置 | 查机械卡滞 |

### FAULT 恢复步骤
1. 右开关拨**下档**断电（急停），人工排除机械问题、确认平台状态；
2. 右开关拨**中档**重新使能；
3. 左开关**下→中**一次 = 重新校准；
4. 校准通过后继续正常流程。

### 失能/失联时的行为（不用慌）
| 情况 | 行为 |
|---|---|
| 右开关下档 / 遥控器离线 | 全部电机断输出；**舵机保持卡位角**（不会误放） |
| 校准中失能 | 零点作废，重新使能自动重校 |
| 储能中失能 | 重新使能后**先把挡块退回释放位置**（日志 `recovery retract done`），再重新储能 |
| 就绪后失能再使能 | 平台仍被扳机锁住，直接重新储能即可（不会多拉伸） |
| 发射中失能 | 舵机停在当前位置；重新使能后按待机处理，必要时手动确认平台状态 |

## 七、参数标定速查（`UserApp/robot/dart/robot_config.h`）

> **单位说明：所有电机角度是转子侧**（编码器在减速箱前）。3508 输出轴角度 = 总角度 ÷ 19.2；2006 输出轴角度 = 总角度 ÷ 36。按机构行程填宏时先换算。

| 宏 | 含义 | 当前值 | 何时改 |
|---|---|---|---|
| `DART_BELT_CHARGE_DEG` | 储能行程（零位起，储能方向） | 360° | **必标定**，且必须小于滑台行程 |
| `DART_BELT_CALI_DIRECTION` | 同步带释放方向符号 | -1 | 零点跑到另一头时 |
| `DART_SCREW_CALI_DIRECTION` | 丝杆零点方向（=最小射力端） | -1 | 零点方向错时 |
| `DART_SCREW_POS_DEFAULT/MIN/MAX_DEG` | 射力默认/下限/上限（相对丝杆零点） | 30 / 10 / 90 | 按实机行程与所需射力 |
| `DART_SERVO_CATCH_DEG` | 舵机卡位角（扣住平台） | 135° | 调试档扫出来填 |
| `DART_SERVO_RELEASE_DEG` | 舵机释放角（发射） | 0° | 同上 |
| `DART_SERVO_ANGLE_MAX_DEG` | 舵机行程上限 | 270° | 180° 舵机改 180 |
| `DART_BELT_CHARGE_SPEED_DPS` | 储能拉拽限速 | 120°/s | 手感/安全调整 |
| `DART_BELT_HOME_SPEED_DPS` | 挡块回撤限速 | 120°/s | 同上 |
| `DART_CALI_*_TIMEOUT_MS` | 校准超时 | 8000ms | 上电位置离限位远时调大 |
| `DART_SCREW_ADJ_DPS` | 射力调节速度 | 60°/s | 调节手感 |

电机接线（CAN1）：yaw=1，同步带=2/4（左 4 右 2），丝杆=3；不对就改 `DART_*_CAN_ID`。方向不对优先改 `DART_*_REVERSE`，不要改代码取反。

## 八、一分钟速记（老手版）

1. 上电前确认**已卸压**；右开关下档上电。
2. 首次/换线：右开关**上档**进调试，点动验方向、扫舵机记角度，填宏烧录。
3. 右开关**中档** → 自动校准（十几秒）→ 日志 `calibration done`。
4. 右摇杆竖直调射力 → 左开关**下→中**储能（~6s，`charged, ready to fire`）→ 左开关**中→上**发射。
5. 连发重复第 4 步；射力改动后要重新储能。
6. 任何 `fault:` = FAULT：右开关下档 → 排查 → 中档 → 左开关下→中 重校准。
7. 急停永远是右开关下档；拨轮是坏的，别用。
