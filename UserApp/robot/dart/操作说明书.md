# 飞镖发射架操作说明书

适用固件：`UserApp/robot/dart/`（分支 `feat/dart-launcher`，对应提交 `8e289f0a` + 工作区修改，最后更新 2026-10-06）
控制器：STM32F407 单板，遥控器 DR16（DBUS / huart3）
机构：yaw（M2006）+ 同步带 ×2（M3508 + P19）+ 扳机丝杆（M3508 + P19）+ 扳机舵机（270° PWM 舵机）

---

## ⚠ 安全须知（务必先读）

1. **侧边拨轮已损坏弃用**，不要拨它；原拨轮功能全部移到**右摇杆竖直**。
2. **上电前确认已卸压**：发射平台没有被扳机锁住、拉簧处于放松状态。上电使能会自动做零位校准——**只动同步带**（顶释放方向硬限位后回撤），**不动扳机丝杆**；但机构里若存着弹性势能，被带动的部件仍可能意外动作，所以一律要求先卸压。
3. **急停：右开关拨到下档**，任何时刻立即断全部电机输出。遥控器离线同样自动停机。首次调试**右手始终搭在右开关上**。
4. 发射（左开关拨上）只在“已储能/就绪”状态有效——但**不要把上档当试探档**，就绪后拨上就是真发射。
5. 校准/储能过程中人不要在发射平台活动范围内。同步带滑台行程约 **1 m**，挡块拖平台后移距离可到米级。
6. **行程参数必须按实机标定。** 按带轮直径 33.62 mm、减速比 19 算，转子角度 = 机构 mm × 64.76。当前 `robot_config.h`：储能行程 `DART_BELT_CHARGE_DEG=36000°`（≈556 mm）已按实机标定；回撤/释放位置 `DART_BELT_CALI_BACKOFF_DEG=360°`（≈5.6 mm）**仍需复核挡块是否确实让开**（见第七章）。
7. **调试档舵机是角度增量控制**：推摇杆才动，**松手即停在当前位置**，不会跳回某个绝对角——但仍禁止快速满杆甩动。

## 一、机构与坐标约定

| 执行器 | 型号 | 作用 | 控制 |
|---|---|---|---|
| yaw | M2006 ×1 | 发射架方位 | 角度环串级 PID |
| 同步带 | M3508 ×2（水平对置） | 挡块拖平台储能 | 位置环串级，严格同步 |
| 扳机丝杆 | M3508 ×1 | 调卡位 → 拉簧拉伸量 → 射力 | 位置环串级 |
| 扳机舵机 | 270° PWM 舵机 | 发射动作（扣/放） | 开环；调试档为**角度增量** |

**逻辑坐标：**

- 同步带：0 = 释放方向硬限位（校准顶到），正 = 储能方向
- 丝杆：0 = **开机位置**（不做自动校零），数值越大射力越大；`DART_SCREW_POS_*` 均相对开机位置
- yaw：0 = 开机位置
- 舵机：直接给角度（0~270°）

### 同步带机械换算（必读）

| 量 | 值 |
|---|---|
| 带轮**直径** | **33.62 mm**（半径 16.81 mm） |
| 带轮周长 | πd ≈ **105.62 mm / 圈** |
| 减速比（M3508 + P19） | **19 : 1** |
| 输出轴 1° | ≈ **0.293 mm** |
| **转子 1°** | ≈ **0.0154 mm** |
| 转子 1000° | ≈ 15.4 mm |
| 滑块满行程（**实测 ≈ 757 mm**） | ≈ 2 580°（输出轴）≈ **49 000°（转子）** |

**填宏公式（宏里全是转子侧角度）：**

```
转子角度 = 行程(mm) ÷ 105.62 × 360 × 19
        ≈ 行程(mm) × 64.76

行程(mm) = 转子角度 ÷ 64.76
```

**行程速查：**

| 机构行程 | 输出轴 | 转子侧（填宏） |
|---|---|---|
| 30 mm | 102° | 1 943° |
| 50 mm | 170° | 3 238° |
| 80 mm | 273° | 5 181° |
| 100 mm | 341° | 6 476° |
| 150 mm | 511° | 9 714° |
| 200 mm | 682° | 12 952° |
| 300 mm | 1 023° | 19 428° |

**速度速查：**

| 转子侧 | 机构速度 |
|---|---|
| 8°/s | ≈ 0.12 mm/s（过慢） |
| 120°/s | ≈ 1.9 mm/s |
| 360°/s | ≈ 5.6 mm/s |
| 1 000°/s | ≈ 15.4 mm/s（校准顶限位/回撤限速） |
| 3 000°/s | ≈ 46 mm/s |
| 10 000°/s | ≈ 154 mm/s（调试点动满杆） |

> 丝杆减速比同为 19，但行程由**丝杆导程**决定，**不要**用带轮公式。先在调试档点动测：输出轴转一圈，扳机位移多少毫米，再换算。3508 输出轴 = 转子 ÷ 19；2006 输出轴 = 转子 ÷ 36。

## 二、上电前检查清单

### A. 机械

- [ ] 同步带张紧合适，挡块固定牢靠
- [ ] **释放方向硬限位块已安装**（校准要顶它），储能方向末端挡块/滑台限位已确认
- [ ] 发射平台、扳机棘爪、丝杆螺母无卡滞；全行程手推滑块顺畅
- [ ] 发射平台已卸压（拉簧放松、平台未被扳机卡住）
- [ ] 飞镖未上弦，或明确准备发射

### B. 电气

- [ ] 电机 CAN 线序：yaw=1，丝杆=3，同步带左=4 / 右=2（CAN1）
- [ ] 舵机信号线接 TIM 对应通道（默认 TIM1_CH1，见 `DART_SERVO_PWM_TIM`）
- [ ] 蜂鸣器在 TIM4_CH3（F4 板载，固件已绑定）
- [ ] 电源电压正常，急停路径可用

### C. 操作

- [ ] 发射架周围无人，炮口/发射方向安全，挡好防弹挡板
- [ ] 遥控器已开机并连接
- [ ] **右开关置于下档（安全位）再上电**
- [ ] **首次上电/装配后：必须走第三章，禁止直接走正常流程**
- [ ] **双人操作**：一人守急停（右开关），一人观察机构

## 三、首次上电 / 装配调试（必做）

> 目标：在**不跑全自动校准、不储能**的前提下，把方向、舵机角、零点方向全部确认并写进 `robot_config.h`。
> 全程右手搭右开关，**任何异常立刻拨下档**。

### 阶段 0：机械与电气点检

按第二章清单打勾。断电手推滑块全行程、手转带轮确认无卡。确认**释放方向硬限位**的位置（校准要顶它）。

### 阶段 1：只通电，不使能

1. 右开关**下档**，上电。
2. RTT 出现 `[dart] robot init done` = 固件已运行。
3. 确认遥控器在线；离线会循环 **COMM_LOST**（急促三连滴）。
4. 此时电机无力矩，手拨机构应能动（再确认不会突然自行动）。

**RTT 无输出排查：** 供电 → SWD/RTT → `CMakeLists.txt` 是否 `ROBOT_TYPE=dart` → 烧录是否成功。不要进入阶段 2。

### 阶段 2：调试档点动验方向（关键）

右开关拨**上档** → 使能但**不自动校准**，听到「短高滴 ×2」。
校准完成前力矩被钳在 **1000/16384**（丝杆 3000/16384），**电机发软是正常的**。

> **调试档 = 纯手动（硬规则）**
> - 拨到上档会**立即中止正在进行的自动校准/储能**（例如先在中档使能、校准已经开顶限位了）：
>   校准中止=零点作废、RTT 打 `[dart] auto calibration aborted: debug mode`；储能中止=挡块自动回撤释放位置后才可点动（RTT 打 `charge sequence aborted`）。
> - 调试档内**不接受任何左开关命令**（校准/储能/发射全部拒绝）：拨左开关只会听到「拒绝」提示音、RTT 打 `xxx command ignored in debug mode`。
> - 要校准/储能/发射：**拨回中档**再操作（校准 = 左开关下→中）。校准完成后再拨上档验方向也可以。

#### 调试档摇杆方向对照（每一条都要实机核对）

> **摇杆分组（防误动设计）**：左摇杆 = 同步带 + yaw，右摇杆 = 扳机（丝杆 + 舵机）——拉同步带时手不会碰到扳机轴，不会误改射力；同一执行器在正常/调试档保持同一摇杆轴，切换档位不换手。

| 摇杆 | 推的方向 | **应当看到的机构效果** | 若相反/无效 |
|---|---|---|---|
| **左摇杆竖直** | **上推** | 双同步带电机同向转，挡块朝**储能方向**移动（能拖住平台往"拉"的方向走） | 两侧一起改 `DART_BELT_L_REVERSE` / `DART_BELT_R_REVERSE` |
| **左摇杆竖直** | **下推** | 挡块朝**释放方向**（硬限位那边）移动 | 同上 |
| **左摇杆水平** | **右推** | 发射架 yaw 朝正方向转（水平面内） | 改 `DART_YAW_REVERSE` |
| **左摇杆水平** | **左推** | yaw 朝反方向转 | 同上 |
| **右摇杆竖直** | **上推** | 丝杆转动，扳机位置朝**射力增大**方向移动（拉簧更紧/棘爪更靠行程远端） | 改 `DART_SCREW_REVERSE` |
| **右摇杆竖直** | **下推** | 扳机位置朝**射力减小**（最小射力端）移动 | 同上 |
| **右摇杆水平** | **右推** | 舵机角度**增大**（增量，推着才动） | 确认无机械干涉后继续；若全程不动查 PWM |
| **右摇杆水平** | **左推** | 舵机角度**减小** | 同上 |
| **右摇杆水平** | **松手** | 舵机**停在当前位置不动**（不会跳变） | 若松手跳变=固件不对，停止调试 |

补充约束：

- 同步带点动满杆 = `DART_DEBUG_BELT_MAX_SPEED_DPS`（10 000°/s ≈ **154 mm/s**），先**轻推 1~2 s** 观察，不要满杆长按。
- **同步带两侧是位置环同步的**（重点）：摇杆只给速率，固件把速率积分成**两侧共用的位置目标**，两侧位置环跟踪同一目标 —— 两侧速度差**不会累计**成位置偏差（与储能流程同一机制）。摇杆回中后**目标保持**（位置环顶住，不会自己滑走），并以 `DART_DEBUG_BELT_SYNC_SPEED_DPS` 限速自动收敛进入点动时已有的偏差。
  - RTT 每 500 ms 打一行 `[dart] debug jog spd L/R, pos L/R, dev err cur L/R iout`：`dev` = 相对进入点动时的两侧偏差，`err` = 目标−实际，`cur` = 实际电流，`iout` = 速度环积分项。
  - **`dev` 持续增大** → 有一侧方向配反（`DART_BELT_L_REVERSE` / `DART_BELT_R_REVERSE`）或有一侧未使能/离线；"两侧转速看着不一样"先看这行日志再动手。
  - 顶到机械限位后目标会**暂停积分**（`DART_DEBUG_BELT_MAX_ERR_DEG`），摇杆反向立即回走，不需要"等回绕"。
  - **松手即停**：点动中目标"领跑"实际最多 500°（追杆滞后），松手瞬间目标自动收回实际位置——否则机构会继续追这段滞后量（"松手后飘一段才停"）。松手后目标保持，位置环顶住。
  - **反向打杆时目标会先重同步到实际位置**，所以不会出现"先往原方向走一段才反向"。
  - **松手后锁不住、往释放方向漂**：松手时速度给定为 0，保持力矩**只来自速度环的积分项**，而它被 `f_Integral_Limit` 硬钳在积分限幅上。看日志里 `iout` 是否贴着限幅、`err` 是否稳定在某个正/负值：
    - 未校准（调试建档阶段）用的是 `DART_BELT_CALI_INTEGRAL_LIMIT`（当前 1000）；
    - 已校准后用的是 `DART_BELT_INTEGRAL_LIMIT`（当前 8000）；
    - `iout` 贴限幅还锁不住 → 继续调大（上限参考 `DART_BELT_MAX_OUT`）。
- 舵机**从当前角（上电默认=卡位角 135°）附近缓慢小范围**试探，**禁止满杆甩**。记下：
  - 「扣住发射平台」→ `DART_SERVO_CATCH_DEG`
  - 「完全释放/不挡平台」→ `DART_SERVO_RELEASE_DEG`
- ~~丝杆零点方向 `DART_SCREW_CALI_DIRECTION`~~：**[已停用]** 自动校准不再做丝杆校零（丝杆代码已 `#if 0`），这步跳过；丝杆零点 = 开机位置，`DART_SCREW_POS_*` 是相对开机位置的角度。
- 同步带 `DART_BELT_CALI_DIRECTION`（-1）：校准顶的是**释放方向**硬限位。可先点动到该限位附近再短测校准。

**立即停手（右开关下档）的现象：** 异响、焦味、单侧不动、方向与上表不符、舵机打到机构、抖动/啸叫、松手后机构仍在动。

### 阶段 3：量行程、换算、填宏

1. **同步带**（卷尺量挡块位移 mm）：
   - `DART_BELT_CALI_BACKOFF_DEG`（= `HOME` 释放位置）：从硬限位退到“挡块让开发射平台”所需 **mm × 64.76**。
     *例：让开 50 mm → 3 238°（不是 360°）。*
   - `DART_BELT_CHARGE_DEG`：储能拉平台的 **mm × 64.76**。
     *例：拉 200 mm → 12 952°。必须小于滑台可走行程。*
2. **丝杆**：点动测导程（输出轴一圈 → 扳机 mm），再定 `DART_SCREW_POS_DEFAULT/MIN/MAX_DEG`。`MIN ≥ DART_SCREW_CALI_BACKOFF_DEG`。
3. **校准速度**建议：顶限位 **5~15 mm/s**（转子约 320~1000°/s）。当前代码顶限位与回撤均为 `1000°/s`≈15.4 mm/s（`DART_BELT_CALI_SPEED_DPS` / `DART_BELT_CALI_BACKOFF_SPEED_DPS`）；**不要**用 8°/s（0.12 mm/s）。
4. **校准超时**：`超时(ms) ≥ 行程(mm)÷机构速度(mm/s)×1000×1.5`。实测全程 49 000°（≈757 mm）@ 1000°/s ⇒ 约 **49 s**，顶限位步超时已按此改为 **75 000 ms**；**改行程/校准速度必须同步改超时**（超时比行程短会必报故障）。
5. 写入 `robot_config.h` 后**重新编译烧录**。

### 阶段 4：首次自动校准

1. 确认平台仍卸压；右开关回**下档**再拨**中档** → 开始校准。

| 步骤 | 机构动作 | 声音 / 日志 |
|---|---|---|
| ① 同步带找零点 | 两电机朝释放方向顶硬限位 | 校准开始：渐高三连滴 |
| ② 同步带回撤 | 退到释放位置 | `belt zero found...` → **校准完成：Mi-So 双音** |
| ~~③④ 丝杆找零点/就位~~ | **已停用**：自动校准不再动丝杆，丝杆以“开机位置”为零点 | — |

> **超时与速度要自洽**（曾踩过）：①步用 `DART_BELT_CALI_TIMEOUT_MS`（默认 8 s，须覆盖"上电位置→限位"的行程）；
> ②步超时**按 `DART_BELT_CALI_BACKOFF_DEG / DART_BELT_CALI_BACKOFF_SPEED_DPS` 动态计算**（+2 s 余量），
> 所以不会再出现"360° ÷ 20°/s = 18 s 却按 8 s 判超时"这类必然故障。
> - 当前顶限位/回撤速度均为 **1000°/s**（≈15.4 mm/s）：再快会硬砸限位（皮带弹性回弹还可能让堵转判定攒不满 0.5 s）；
> - 堵转判定用**速度阈值**（`DART_CALI_STALL_SPEED_DPS=100°/s` 持续 `DART_CALI_STALL_MS=500 ms`，起步 `DART_CALI_START_GRACE_MS=500 ms` 宽限），**不用** PID 堵转标志位（置位后会残留到下一阶段误判，见第十章）。

> 丝杆不做自动校零的后果：`DART_SCREW_POS_*`（射力位置）是**相对开机位置**的，每次上电的绝对射力会跟着开机位置漂。要跨上电绝对重复，需要恢复 `dart_launcher.c` 里 `#if 0` 的丝杆校准段（文件内有恢复步骤注释）。
>
> 另外：**上电后丝杆停在原位不动**（不会自己走到默认射力位置），储能前要先确认/用右摇杆竖直拨好射力；否则就按“开机位置”对应的射力执行。

2. 失败见第六章。第一次失败很正常：下档 → 排查 → 重来。
3. **异常立即急停的情形**：顶限位方向与预期相反、单侧不动、超时进 FAULT、机械撞击。

### 阶段 5：小能量试跑 → 试射

1. 射力拨到**最小**（正常档右摇杆竖直下推到底）。
2. 左开关下→中 储能：单中鸣开始；**盯挡块行程**是否等于标定 mm；约数秒后「So-Do′ + SUCCESS」= 就绪。
3. 行程不对/异常 → 右开关下档 → 回阶段 3。
4. 空跑正确后再装飞镖，**小射力打第一发**（左开关中→上；听到发射瞬间高音短脉冲）。
5. 检查弹着与机构损伤，逐步加大射力。**禁止第一次就满射力。**

## 四、遥控器映射总表

| 输入 | 正常档（右开关**中**） | 调试档（右开关**上**） |
|---|---|---|
| **右开关** | 下=急停 / **中=使能**（首次使能自动校准） | **上=使能 + 调试点动**（**不**自动校准） |
| **左开关** | 下=待机；**进中档=储能**（下→中；故障/未校准=重新校准；**下→上**快速扫过中档同样=储能）；**中→上=发射**（两段式，必须经过中档） | 同左 |
| **左摇杆水平** | **右推 = yaw 正方向**，满杆 `DART_YAW_SENSITIVITY_DPS`（当前 80 000°/s 转子侧目标推进速率） | 同左（两档同轴） |
| **左摇杆竖直** | — | **上推 = 同步带储能方向**，下推 = 释放方向 |
| **右摇杆竖直** | **上推 = 射力增大**，下推 = 减小（丝杆） | **上推 = 丝杆点动（射力+）**，下推 = 射力−（两档同轴） |
| **右摇杆水平** | — | **右推 = 舵机角+，左推 = 舵机角−（增量，松手即停）** |

要点：

- **摇杆分组（防误动）**：左摇杆 = 同步带 + yaw，右摇杆 = 扳机（丝杆 + 舵机）；拉同步带时手不会碰到扳机轴，不会误改射力。同一执行器两档同轴，切换档位不换手。

- 左开关命令是**拨动瞬间触发**（上升沿），停在档位不重复。
- 射力**仅待机可调**（就绪后扳机带载锁着平台，不许动丝杆），调好后**重新储能**才生效。
- yaw 任何使能状态可用。
- 调试点动**在 IDLE/READY 生效**（READY 只动同步带——平台被扳机锁住，丝杆/舵机锁定）；校准/储能/发射序列自动接管。
- 退出调试档（回中档）后若已校准，同步带会自动回释放位置，注意挡块回位动作。

## 五、正常工作流程（一发）

### 1. 校准（每次上电一次）

右开关**中档**使能后自动开始（中断/失败：左开关**下→中**重来）。
日志：`start zero calibration (belt only)` → `belt zero found ...` → `calibration done (belt only)`（**丝杆不参与校零**，没有 `screw zero found`）。
长行程时耗时可达分钟级，属正常（按 mm/s 估算）。

### 2. 调射力（可选）

正常档右摇杆竖直，**仅待机（IDLE）可调**——就绪后不能调：平台被扳机锁住、拉簧带载，动丝杆有误释放/卡滞风险。要改射力：发射回待机后调，再重新储能。

### 3. 储能

左开关**下→中**：丝杆到射力位 → 同步带拉平台后移标定行程 → 限速回到释放位置。
完成：`charged, ready to fire` + 就绪音。耗时 ≈ 行程 ÷ 储能限速。

### 4. 发射

左开关**中→上**：舵机到释放角 → 弹射 → 回卡位 → 回待机（约 1.1 s）。

### 5. 连发

每发重复 2→3→4。发射后必须重新储能。打完右开关下档收工。

## 六、故障与恢复

| 日志 | 原因 | 处理 |
|---|---|---|
| `fault: belt calibration stall timeout` | 超时没顶到限位：方向反 / 离限位远 / 速度过慢 | 查 `DART_BELT_CALI_DIRECTION`；按 mm/s 重算限速与超时 |
| ~~`fault: screw calibration stall/backoff timeout`~~ | **[已停用]** 丝杆校准 `#if 0`，当前固件不会出现 | 恢复丝杆校准时才涉及 `DART_SCREW_CALI_DIRECTION` |
| `fault: belt calibration backoff timeout` | 回撤卡住或目标不可达 | 查机械、行程宏是否按 ×64.76 填 |
| `fault: screw not in position before charge` | 储能前丝杆 2 s 没就位 | 查丝杆 / `DART_SCREW_POS_*` |
| `fault: belt stalled during charge far from target` | 离目标还很远就**两侧同时**顶死 = 真卡滞/超行程（**拉到机械末端是正常完成**，距目标 <`DART_BELT_END_TOL_DEG` 顶死不判故障；单侧慢=负载不均，自动纠偏不停机） | 查机械卡滞；`DART_BELT_CHARGE_DEG` 按 mm 重标 |
| `fault: charge timeout` | 拉不到目标 | 查行程宏、限速、机构 |
| `fault: retract timeout` | 回不到释放位置 | 查机械卡滞 |

### FAULT 恢复

> **FAULT 不断力矩**：弹簧负载下断力矩=机构被拉簧带飞（失控加速+反拖发电，反电动势过压，实车险些打坏硬件）。故障时电机**保持故障位置**（限力），丝杆保持、舵机回卡位角、yaw 断力矩；**右开关下档才是真正断输出**——下档前确认机构无弹性能。

1. 右开关**下档**，排除机械问题，确认平台是否仍锁住/已射；
2. 右开关**中档**；
3. 左开关**下→中**重新校准；
4. 通过后继续。

> **注意：FAULT 后只把右开关下→中（重新使能）不会自动重校**——故障态下使能不会触发自动校准，电机也会保持停机，**必须再拨一次左开关（下→中）** 才会发起校准；且必须在正常档（中档），调试档会拒绝校准命令。

### 失能/失联行为

| 情况 | 行为 |
|---|---|
| 右开关下档 / 遥控器离线 | 电机断输出；**舵机保持当前角**（上电后正常态=卡位角，不会误放） |
| 校准中失能 | 零点作废，重新使能自动重校 |
| 储能中失能 | 再使能后先回撤挡块（`recovery retract done`）再储能 |
| 就绪后失能再使能 | **状态保持 READY**（平台仍被锁，无需重校准），可直接发射；要再储能须先发射回待机 |
| 发射中失能 | 舵机停当前角；再使能后按待机处理且**舵机自动回卡位角**，必要时人工确认平台 |

**掉了遥控（`[rc] remote control lost`）或看到 `[bsp_usart] USART error` 时怎么查**：
1. 看错误类型（`bsp_usart` 会打印 `ErrorCode`）：**ORE**=溢出（CPU/中断来不及、日志太多）；**FE/NE/PE**=帧错/噪声/校验错 → **线上干扰**（走线、共地、EMI）。NE 连续刷 = RX 线上有毛刺，正常链路应为 0。
2. 噪声的后果：帧被中断丢弃 → 连续丢帧 → 100 ms 判掉线 → 失能（滴滴）+ 持续失联指示（乱响）。频繁发作先查硬件（见下）。
3. 硬件排查顺序：①拔舵机信号线 ②右开关下档让电机不输出 ③只给接收机供电 —— 看 NE 是否归零，定位干扰源；然后共地/星形接地、接收机独立供电、DBUS 线双绞屏蔽远离动力线、MCU RX 加 RC（串 100 Ω + 对地 1 nF）。
4. 本车遥控器的 18 字节帧 **帧尾 [16]/[17] 不是 CRC16，是拨轮字段**（实测 `crc16(first16)=0x111B` vs `tail=0x0400`），所以不能做 CRC 校验，只能靠硬件降噪。

接线（CAN1）：yaw=1，同步带左=4 / 右=2，丝杆=3。方向优先改 `DART_*_REVERSE`，不要改代码取反。

## 八、正常流程速记（老手版）

1. 卸压；右开关下档上电。
2. 首次/装配：右开关**上档** → 按方向表点动验向、增量扫舵机、量 mm×64.76 填宏 → 烧录。
3. 右开关**中档**自动校准（长行程要等）→ 校准完成音。
4. 右摇杆竖直调射力 → 左开关下→中储能 → 中→上发射。
5. 连发重复 4；射力改动后重新储能。
6. `fault:` → 下档排查 → 中档 → 左开关下→中 重校准。
7. 急停永远是右开关下档；拨轮已弃用。

| 校准完成 | 上行双音 Mi-So | 进入待机，可储能 | `HandleCalibrating()` 回撤到位 |
| 储能开始 | 单中鸣（E5） | 开始拉拽 | `HandleCommand()` 储能命令被接受 |
| 储能完成 | 上行 So-Do′ + SUCCESS | **就绪，可发射** | `HandleCharging()` 复位到位进 READY |
| 发射瞬间 | 极短高音脉冲（G6） | 舵机释放 | `HandleCommand()` 发射命令被接受 |
| 发射完成 | 短滴 | 回待机 | `HandleFiring()` 序列结束 |
| 命令被忽略 | WARNING 双短 | 状态不满足 | `HandleCommand()` 各拒绝分支（见下） |

「命令被忽略」的具体触发（每个都会打 RTT 日志说明原因）：

| 情形 | 条件 |
|---|---|
| 调试档拨左开关（任何档） | 调试档不接受序列命令——校准/储能/发射全部拒绝（`xxx command ignored in debug mode`） |
| 校准命令但状态不对 | 既不在 IDLE 也不在 FAULT（`calibrate command ignored`） |
| 储能命令正在回撤 | 上次储能被失能中止、挡块还没回释放位（`charge ignored: recovery retract in progress`） |
| 储能门槛不满足 | 非 IDLE / 未校准 / 有待回撤（`charge ignored: state=...`） |
| 发射命令但非 READY | 没储能就拨上档（`fire command ignored`） |

### 持续 / 警告

| 模式 | 听感 | 何时 | 触发入口 |
|---|---|---|---|
| **WARNING** | A5 双短「嘀、嘀—」，停 0.6 s 循环 | 命令拒绝等（一次性） | `DartBuzzerCmdRejected()` ← `HandleCommand()` |
| **ERROR** | 高低「嘟—呜—」，停 0.6 s 循环 | **FAULT**：响一次 + 持续到重新校准 | `EnterFault()`；`StartCalibration()` 时清除 |
| **COMM_LOST** | 急促「嘀嘀嘀」三连，停 0.68 s 循环 | 遥控器离线，恢复后解除 | `SafetyUpdate()` 离线沿；恢复沿 `DartBuzzerRcOk()` 清除 |

### 首次上电“声音时间线”

1. 上电（右开关下档）：若遥控未连 → **COMM_LOST 循环**
2. 右开关上档：使能短滴 + 调试双滴
3. 校准：三连滴 →（长动作）→ **Mi-So**
4. 储能：单中鸣 → 就绪 **So-Do′**
5. 发射：高音短脉冲 → 完成短滴
6. **低双鸣 = 急停**；**ERROR 循环 = FAULT**

> 调试档只点动验方向时不应出现校准音。**一上电就开始顶限位 = 你拨的是中档不是上档，立刻急停。**

## 十、固件内部逻辑速览（状态机 / 自动校准 / 一键储能）

> 面向调试与改参，普通操作可跳过。实现见 `dart_launcher.c`。

### 状态机（`Dart_State_e`）

```
上电 ──► IDLE（挡块=释放位，舵机=卡位角，丝杆=开机位置）
           │  正常档首次使能自动校准 / 左开关下→中（未校准或故障时=校准命令）
           ▼
      CALIBRATING ──两步完成──► IDLE（is_calibrated=1）
           │超时/堵转异常                    │ 左开关下→中（储能命令）
           ▼                                ▼
        FAULT ──重新校准──► CALIBRATING   CHARGING ──三步完成──► READY
        （停机+ERROR）                                      │ 左开关中→上
                                                            ▼
                            IDLE ◄──发射序列结束── FIRING（舵机按时间推进）
```

| 状态 | 行为 | 进入条件 | 离开条件 |
|---|---|---|---|
| IDLE | 挡块保持释放位；可调射力/点动 | 上电、序列完成/中止 | 校准或储能命令 |
| CALIBRATING | ①双带低力矩顶释放方向硬限位（两侧都堵转才算零点）②位置环回撤 `DART_BELT_HOME_DEG` | 使能+auto_cali，或校准命令（IDLE/FAULT） | 完成→IDLE；超时→FAULT |
| CHARGING | ①丝杆就位 ②双带同步拉 `DART_BELT_CHARGE_DEG`（行程判完成+堵转看门狗）③限速回释放位 | 储能命令（门槛见下） | 完成→READY；超时/堵转→FAULT |
| READY | 挡块保持释放位，平台被扳机锁住 | 储能完成 | 发射命令→FIRING |
| FIRING | 舵机释放角→保持 `DART_FIRE_DWELL_MS`→回卡位角 | 发射命令（仅 READY） | 结束→IDLE |
| FAULT | 电机停机、舵机回卡位角、ERROR 音+持续指示 | 任一超时/堵转异常 | **只能重新校准**恢复 |

注意：**失能/失联打断序列时**，校准中→零点作废；储能中→`recovery_retract`（再使能先自动回撤挡块，撤完才能储能）；READY 保持不变（可直接发射）；发射中→回 IDLE、舵机再使能时自动回卡位角。**调试档（右开关上）= 纯手动**：会中止进行中的校准/储能（储能中止后挡块自动回撤，撤完才可点动），且拒绝一切左开关命令（校准/储能/发射都拒绝）。

### 自动校准（当前只做同步带）

1. 入口：正常档首次使能自动开始（`DartLauncherSetEnable(auto_cali=true)`），或左开关下→中（故障/未校准时派发 `DART_CMD_CALIBRATE`）；
2. 全程力矩钳在 `DART_BELT_CALI_MAX_OUT / DART_BELT_CALI_INTEGRAL_LIMIT`（校准完成后切到正常限幅）；
3. 顶限位步：双带以 `DART_BELT_CALI_DIRECTION × DART_BELT_CALI_SPEED_DPS` 速度环推进，**堵转判据=速度阈值**（实测速度 < `DART_CALI_STALL_SPEED_DPS` 持续 `DART_CALI_STALL_MS`，起步有 `DART_CALI_START_GRACE_MS` 宽限）；**两侧各自**顶到后把各自编码器值记为 `belt_zero_offset[i]`（顺带完成两侧零点同步），超时 `DART_BELT_CALI_TIMEOUT_MS`→FAULT；
4. 回撤步：位置环走 `DART_BELT_HOME_DEG`，限速 `DART_BELT_CALI_BACKOFF_SPEED_DPS`，到位判据=两带误差均 < `DART_BELT_POS_TOL_DEG`；超时按 `BACKOFF_DEG/BACKOFF_SPEED + 4 s` 动态算→FAULT；
5. **丝杆不参与**（校准代码 `#if 0` 保留）：丝杆零点=开机位置，`DART_SCREW_POS_*` 均相对开机位置，跨上电绝对重复需恢复丝杆校零。

### 一键储能运行条件（全部满足）

1. 遥控器在线、右开关非下档（使能）；
2. 左开关命令触发（`robot.c RCCommandUpdate()`，**任务侧边沿检测**）：**进中档**（下→中；下→上快速扫过中档也算）= 储能命令；**中→上** = 发射命令（两段式防误发）。
   @note 历史坑：遥控器模块的 TEMP/LAST 在串口回调里就互相拷贝，任务侧拿它做边沿检测只能靠中断竞态"碰"（~3% 概率触发）——表现为拨左开关**偶尔**响拒绝音、多数时候无声无息。现已改为任务侧自记上一帧开关值，100% 可靠。
3. `HandleCommand()` 门槛：**状态=IDLE** 且 **is_calibrated=1** 且 **无 recovery_retract** 且 **非调试档**（不满足→WARNING 音+日志给出实际值；状态=FAULT 或未校准时左开关下→中派发的是**校准命令**而非储能）；
4. 序列内自检：丝杆 `DART_SCREW_SETTLE_TIMEOUT_MS` 内就位（±`DART_SCREW_POS_TOL_DEG`）→ 拉到位（±`DART_BELT_POS_TOL_DEG`）→ 回撤到位；期间堵转看门狗（`DART_CHARGE_STALL_*`，**两侧同时转不动**才判）或超时（`DART_CHARGE_TIMEOUT_MS` / `DART_RETRACT_TIMEOUT_MS`）触发即 FAULT。射力（丝杆位置）**仅 IDLE 可调**，调好再储能。

### 双带同步与均载（共模/差模解耦，`BeltSyncUpdate`）

双带电机位置控制不再各自为战，而是解耦成两个通道（所有阶段共用：校准回撤/储能/复位/点动）：

- **共模环**：两侧**平均位置**跟目标，输出**同一个速度给定**给两台电机 → 两机 P 项一致；
- **差模环（P+I，力矩级）**：两侧**位置差**收敛到基准 → 输出**力矩偏置 ±Ib**（经积分互融注入，`DART_BELT_SYNC_TORQUE_MAX` 钳幅），只纠偏**不停机**、不判故障（`DART_BELT_SYNC_WARN_DEG` 超限只打告警）；
- **积分互融**（`BlendBeltIntegrals`，`DART_BELT_INTEGRAL_BLEND`）：两台速度环积分互相靠拢成共享一份（±Ib 除外），摩擦差异/起动不对称不再被积分固化。

> **重要教训（曾踩两次）**：①差模纠偏**不能走速度给定**——`v_ref` 差经速度环 Kp 放大成 P 项差（`Δu=2×Kp_s×v_diff`），稳态就能差出几千 `real_current`，积分互融根本压不掉，差模必须降到**力矩级**注入；②差模**积分限幅必须远小于输出限幅**——相等时瞬态把积分灌满卡死，持续注入上千偏置：电流差几千、偏差被拖着走、**静止才慢慢回**（积分反向才退出）。
> 稳态电流差 ≈ **2×Ib**（Ib=差模力矩偏置；机械对称时趋 0，负载路径不对称时为补偿所需）。**物理约束**：偏差锁死与完全均流在负载不对称时不可兼得——修完仍差上千就是机械不对称（皮带张紧/对中），查机械或放宽偏差目标。
> 另：对置安装的两台电机 `real_current` **原始符号可能相反**，比较请用绝对值；若读数形如 +3500/−3500 其实是平衡的。

调节：`DART_BELT_POS_KP`（共模追随）、`DART_BELT_SYNC_KP/KD`（纠偏强度/阻尼）、`DART_BELT_INTEGRAL_BLEND`（互融强度，1=完全互融）。

**负载感知双模式**（自动切换，判据=两台 `real_current` 绝对值之和）：
- **带载（>3000）→ 力矩同步**：负载路径不对称（皮带张紧/摩擦/带轮几何差）是机械事实，硬锁偏差=持续较劲=电流差；软基准放行变形差 → **均流**（拉拽/储能保持场景）；
- **空载（<2400）→ 位置同步**：硬基准锁死偏差值 → **两侧走位齐**（空载移动/点动场景）；
- 回差防抖，切换时清差模积分防偏置突跳；RTT 打 `belt sync mode -> torque-balance / position-lock`。

### 堵转判据为什么不用 PID 库的标志位

`PID_ErrorHandle`（`controller.c f_PID_ErrorHandle`）置位后 `ERRORType` **不会自动清零**：`PIDClear()` 不清 `ERRORHandler`，`PIDInit()` 才会清——所以想复用必须手动写 `pid->ERRORHandler.ERRORType = PID_ERROR_NONE`（全仓库只有 `shoot.c` 是这么用的）。且其判据是「偏差/给定 > 0.95 连续 500 次」：小给定（位置环收敛出的小速度给定）+噪声极易误判，起步加速阶段也会误攒计数，没有起步宽限。本机器人改用**独立速度阈值判据**（`CheckStall()`）：与给定大小无关、按阶段显式复位（`ResetStallState()`）无残留、阈值/时长/宽限全部宏可调。详见 `dart_launcher.h` 顶部注释。
