# 飞镖发射架操作说明书

适用固件：`UserApp/robot/dart/`（分支 `feat/dart-launcher`）
控制器：STM32F407 单板，遥控器 DR16（DBUS / huart3）
机构：yaw（M2006）+ 同步带 ×2（M3508 + P19）+ 扳机丝杆（M3508 + P19）+ 扳机舵机（270° PWM 舵机）

---

## ⚠ 安全须知（务必先读）

1. **侧边拨轮已损坏弃用**，不要拨它；原拨轮功能全部移到**右摇杆竖直**。
2. **上电前确认已卸压**：发射平台没有被扳机锁住、拉簧处于放松状态。上电使能会自动做零位校准——**只动同步带**（顶释放方向硬限位后回撤），**不动扳机丝杆**；但机构里若存着弹性势能，被带动的部件仍可能意外动作，所以一律要求先卸压。
3. **急停：右开关拨到下档**，任何时刻立即断全部电机输出。遥控器离线同样自动停机。首次调试**右手始终搭在右开关上**。
4. 发射（左开关拨上）只在“已储能/就绪”状态有效——但**不要把上档当试探档**，就绪后拨上就是真发射。
5. 校准/储能过程中人不要在发射平台活动范围内。同步带滑台行程约 **1 m**，挡块拖平台后移距离可到米级。
6. **行程参数必须按实机标定。** 按带轮直径 33.62 mm、减速比 19 算，当前 `robot_config.h` 里的 **360°（转子）只有约 5.6 mm**，远不够储能/让开，直接跑正式流程会异常（见第七章）。
7. **调试档舵机是角度增量控制**：推摇杆才动，**松手即停在当前位置**，不会跳回某个绝对角——但仍禁止快速满杆甩动。

## 一、机构与坐标约定

| 执行器 | 型号 | 作用 | 控制 |
|---|---|---|---|
| yaw | M2006 ×1 | 发射架方位 | 角度环串级 PID |
| 同步带 | M3508 ×2（水平对置） | 挡块拖平台储能 | 位置环串级，严格同步 |
| 扳机丝杆 | M3508 ×1 | 调卡位 → 拉簧拉伸量 → 射力 | 位置环串级 |
| 扳机舵机 | 270° PWM 舵机 | 发射动作（扣/放） | 开环；调试档为**角度增量** |

**逻辑坐标：**

- 同步带：0 = 释放方向硬限位（校准顶到），正 = 储能方向
- 丝杆：0 = 射力最小端硬限位，数值越大射力越大
- yaw：0 = 开机位置
- 舵机：直接给角度（0~270°）

### 同步带机械换算（必读）

| 量 | 值 |
|---|---|
| 带轮**直径** | **33.62 mm**（半径 16.81 mm） |
| 带轮周长 | πd ≈ **105.62 mm / 圈** |
| 减速比（M3508 + P19） | **19 : 1** |
| 输出轴 1° | ≈ **0.293 mm** |
| **转子 1°** | ≈ **0.0154 mm** |
| 转子 1000° | ≈ 15.4 mm |
| 滑块满行程（约 1 m） | ≈ 3408°（输出轴）≈ **64 760°（转子）** |

**填宏公式（宏里全是转子侧角度）：**

```
转子角度 = 行程(mm) ÷ 105.62 × 360 × 19
        ≈ 行程(mm) × 64.76

行程(mm) = 转子角度 ÷ 64.76
```

**行程速查：**

| 机构行程 | 输出轴 | 转子侧（填宏） |
|---|---|---|
| 30 mm | 102° | 1 943° |
| 50 mm | 170° | 3 238° |
| 80 mm | 273° | 5 181° |
| 100 mm | 341° | 6 476° |
| 150 mm | 511° | 9 714° |
| 200 mm | 682° | 12 952° |
| 300 mm | 1 023° | 19 428° |

**速度速查：**

| 转子侧 | 机构速度 |
|---|---|
| 8°/s | ≈ 0.12 mm/s（过慢） |
| 120°/s | ≈ 1.9 mm/s |
| 360°/s | ≈ 5.6 mm/s |
| 3 000°/s | ≈ 46 mm/s（调试点动满杆） |

> 丝杆减速比同为 19，但行程由**丝杆导程**决定，**不要**用带轮公式。先在调试档点动测：输出轴转一圈，扳机位移多少毫米，再换算。3508 输出轴 = 转子 ÷ 19；2006 输出轴 = 转子 ÷ 36。

## 二、上电前检查清单

### A. 机械

- [ ] 同步带张紧合适，挡块固定牢靠
- [ ] **释放方向硬限位块已安装**（校准要顶它），储能方向末端挡块/滑台限位已确认
- [ ] 发射平台、扳机棘爪、丝杆螺母无卡滞；全行程手推滑块顺畅
- [ ] 发射平台已卸压（拉簧放松、平台未被扳机卡住）
- [ ] 飞镖未上弦，或明确准备发射

### B. 电气

- [ ] 电机 CAN 线序：yaw=1，丝杆=3，同步带左=4 / 右=2（CAN1）
- [ ] 舵机信号线接 TIM 对应通道（默认 TIM1_CH1，见 `DART_SERVO_PWM_TIM`）
- [ ] 蜂鸣器在 TIM4_CH3（F4 板载，固件已绑定）
- [ ] 电源电压正常，急停路径可用

### C. 操作

- [ ] 发射架周围无人，炮口/发射方向安全，挡好防弹挡板
- [ ] 遥控器已开机并连接
- [ ] **右开关置于下档（安全位）再上电**
- [ ] **首次上电/装配后：必须走第三章，禁止直接走正常流程**
- [ ] **双人操作**：一人守急停（右开关），一人观察机构

## 三、首次上电 / 装配调试（必做）

> 目标：在**不跑全自动校准、不储能**的前提下，把方向、舵机角、零点方向全部确认并写进 `robot_config.h`。
> 全程右手搭右开关，**任何异常立刻拨下档**。

### 阶段 0：机械与电气点检

按第二章清单打勾。断电手推滑块全行程、手转带轮确认无卡。确认**释放方向硬限位**的位置（校准要顶它）。

### 阶段 1：只通电，不使能

1. 右开关**下档**，上电。
2. RTT 出现 `[dart] robot init done` = 固件已运行。
3. 确认遥控器在线；离线会循环 **COMM_LOST**（急促三连滴）。
4. 此时电机无力矩，手拨机构应能动（再确认不会突然自行动）。

**RTT 无输出排查：** 供电 → SWD/RTT → `CMakeLists.txt` 是否 `ROBOT_TYPE=dart` → 烧录是否成功。不要进入阶段 2。

### 阶段 2：调试档点动验方向（关键）

右开关拨**上档** → 使能但**不自动校准**，听到「短高滴 ×2」。
校准前力矩被钳在 1500/16384，**电机发软是正常的**。

> **调试档 = 纯手动（硬规则）**
> - 拨到上档会**立即中止正在进行的自动校准**（例如先在中档使能、校准已经开顶限位了），
>   零点作废、RTT 打 `[dart] auto calibration aborted: debug mode`，随即进入可点动状态。
> - 调试档内**不接受校准命令**：拨左开关只会听到「拒绝」提示音、RTT 打 `calibrate command ignored in debug mode`。
> - 要校准：**拨回中档 → 左开关下→中**。校准完成后再拨上档验方向也可以。

#### 调试档摇杆方向对照（每一条都要实机核对）

| 摇杆 | 推的方向 | **应当看到的机构效果** | 若相反/无效 |
|---|---|---|---|
| **左摇杆竖直** | **上推** | 双同步带电机同向转，挡块朝**储能方向**移动（能拖住平台往“拉”的方向走） | 两侧一起改 `DART_BELT_L_REVERSE` / `DART_BELT_R_REVERSE` |
| **左摇杆竖直** | **下推** | 挡块朝**释放方向**（硬限位那边）移动 | 同上 |
| **左摇杆水平** | **右推** | 丝杆转动，扳机位置朝**射力增大**方向移动（拉簧更紧/棘爪更靠行程远端） | 改 `DART_SCREW_REVERSE` |
| **左摇杆水平** | **左推** | 扳机位置朝**射力减小**（最小射力端）移动 | 同上 |
| **右摇杆水平** | **右推** | 发射架 yaw 朝正方向转（水平面内） | 改 `DART_YAW_REVERSE` |
| **右摇杆竖直** | **上推** | 舵机角度**增大**（增量，推着才动） | 确认无机械干涉后继续；若全程不动查 PWM |
| **右摇杆竖直** | **下推** | 舵机角度**减小** | 同上 |
| **右摇杆竖直** | **松手** | 舵机**停在当前位置不动**（不会跳变） | 若松手跳变=固件不对，停止调试 |

补充约束：

- 同步带点动满杆 = `DART_DEBUG_BELT_MAX_SPEED_DPS`（5000°/s ≈ **77 mm/s**），先**轻推 1~2 s** 观察，不要满杆长按。
- **同步带两侧是位置环同步的**（重点）：摇杆只给速率，固件把速率积分成**两侧共用的位置目标**，两侧位置环跟踪同一目标 —— 两侧速度差**不会累计**成位置偏差（与储能流程同一机制）。摇杆回中后**目标保持**（位置环顶住，不会自己滑走），并以 `DART_DEBUG_BELT_SYNC_SPEED_DPS` 限速自动收敛进入点动时已有的偏差。
  - RTT 每 500 ms 打一行 `[dart] debug jog spd L/R, pos L/R, dev err cur L/R iout`：`dev` = 相对进入点动时的两侧偏差，`err` = 目标−实际，`cur` = 实际电流，`iout` = 速度环积分项。
  - **`dev` 持续增大** → 有一侧方向配反（`DART_BELT_L_REVERSE` / `DART_BELT_R_REVERSE`）或有一侧未使能/离线；"两侧转速看着不一样"先看这行日志再动手。
  - 顶到机械限位后目标会**暂停积分**（`DART_DEBUG_BELT_MAX_ERR_DEG`），摇杆反向立即回走，不需要"等回绕"。
  - **反向打杆时目标会先重同步到实际位置**，所以不会出现"先往原方向走一段才反向"。
  - **松手后锁不住、往释放方向漂**：松手时速度给定为 0，保持力矩**只来自速度环的积分项**，而它被 `f_Integral_Limit` 硬钳在积分限幅上。看日志里 `iout` 是否贴着限幅、`err` 是否稳定在某个正/负值：
    - 未校准（调试建档阶段）用的是 `DART_BELT_CALI_INTEGRAL_LIMIT`（当前 4000）；
    - 已校准后用的是 `DART_BELT_INTEGRAL_LIMIT`（当前 8000）；
    - `iout` 贴限幅还锁不住 → 继续调大（上限参考 `DART_BELT_MAX_OUT`）。
- 舵机**从当前角（上电默认=卡位角 135°）附近缓慢小范围**试探，**禁止满杆甩**。记下：
  - 「扣住发射平台」→ `DART_SERVO_CATCH_DEG`
  - 「完全释放/不挡平台」→ `DART_SERVO_RELEASE_DEG`
- ~~丝杆零点方向 `DART_SCREW_CALI_DIRECTION`~~：**[已停用]** 自动校准不再做丝杆校零（丝杆代码已 `#if 0`），这步跳过；丝杆零点 = 开机位置，`DART_SCREW_POS_*` 是相对开机位置的角度。
- 同步带 `DART_BELT_CALI_DIRECTION`（-1）：校准顶的是**释放方向**硬限位。可先点动到该限位附近再短测校准。

**立即停手（右开关下档）的现象：** 异响、焦味、单侧不动、方向与上表不符、舵机打到机构、抖动/啸叫、松手后机构仍在动。

### 阶段 3：量行程、换算、填宏

1. **同步带**（卷尺量挡块位移 mm）：
   - `DART_BELT_CALI_BACKOFF_DEG`（= `HOME` 释放位置）：从硬限位退到“挡块让开发射平台”所需 **mm × 64.76**。
     *例：让开 50 mm → 3 238°（不是 360°）。*
   - `DART_BELT_CHARGE_DEG`：储能拉平台的 **mm × 64.76**。
     *例：拉 200 mm → 12 952°。必须小于滑台可走行程。*
2. **丝杆**：点动测导程（输出轴一圈 → 扳机 mm），再定 `DART_SCREW_POS_DEFAULT/MIN/MAX_DEG`。`MIN ≥ DART_SCREW_CALI_BACKOFF_DEG`。
3. **校准速度**建议：顶限位 **5~10 mm/s**（转子约 320~650°/s），回撤 **10~20 mm/s**。当前代码 `DART_BELT_CALI_SPEED_DPS=360°/s`≈5.6 mm/s，可用；**不要**用 8°/s（0.12 mm/s）。
4. **校准超时**：`超时(ms) ≥ 行程(mm)÷机构速度(mm/s)×1000×1.5`。1 m @ 5.6 mm/s ⇒ 约 **270 s**，现在 8000 ms 必误报。
5. 写入 `robot_config.h` 后**重新编译烧录**。

### 阶段 4：首次自动校准

1. 确认平台仍卸压；右开关回**下档**再拨**中档** → 开始校准。

| 步骤 | 机构动作 | 声音 / 日志 |
|---|---|---|
| ① 同步带找零点 | 两电机朝释放方向低速顶硬限位 | 校准开始：渐高三连滴 |
| ② 同步带回撤 | 退到释放位置 | `belt zero found...` → **校准完成：Mi-So 双音** |
| ~~③④ 丝杆找零点/就位~~ | **已停用**：自动校准不再动丝杆，丝杆以“开机位置”为零点 | — |

> 丝杆不做自动校零的后果：`DART_SCREW_POS_*`（射力位置）是**相对开机位置**的，每次上电的绝对射力会跟着开机位置漂。要跨上电绝对重复，需要恢复 `dart_launcher.c` 里 `#if 0` 的丝杆校准段（文件内有恢复步骤注释）。
>
> 另外：**上电后丝杆停在原位不动**（不会自己走到默认射力位置），储能前要先确认/用右摇杆竖直拨好射力；否则就按“开机位置”对应的射力执行。

2. 失败见第六章。第一次失败很正常：下档 → 排查 → 重来。
3. **异常立即急停的情形**：顶限位方向与预期相反、单侧不动、超时进 FAULT、机械撞击。

### 阶段 5：小能量试跑 → 试射

1. 射力拨到**最小**（正常档右摇杆竖直下推到底）。
2. 左开关下→中 储能：单中鸣开始；**盯挡块行程**是否等于标定 mm；约数秒后「So-Do′ + SUCCESS」= 就绪。
3. 行程不对/异常 → 右开关下档 → 回阶段 3。
4. 空跑正确后再装飞镖，**小射力打第一发**（左开关中→上；听到发射瞬间高音短脉冲）。
5. 检查弹着与机构损伤，逐步加大射力。**禁止第一次就满射力。**

## 四、遥控器映射总表

| 输入 | 正常档（右开关**中**） | 调试档（右开关**上**） |
|---|---|---|
| **右开关** | 下=急停 / **中=使能**（首次使能自动校准） | **上=使能 + 调试点动**（**不**自动校准） |
| **左开关** | 下=待机；**下→中=储能**（故障/未校准=重新校准）；**中→上=发射** | 同左 |
| **右摇杆水平** | **右推 = yaw 正方向**，满杆 60°/s | 同左 |
| **右摇杆竖直** | **上推 = 射力增大**，下推 = 减小 | **上推 = 舵机角+，下推 = 舵机角−（增量，松手即停）** |
| **左摇杆竖直** | — | **上推 = 同步带储能方向**，下推 = 释放方向 |
| **左摇杆水平** | — | **右推 = 丝杆正（射力+）**，左推 = 射力− |

要点：

- 左开关命令是**拨动瞬间触发**（上升沿），停在档位不重复。
- 射力调完**须重新储能**才对当前这发生效。
- yaw 任何使能状态可用。
- 调试点动**仅 IDLE 生效**；校准/储能/发射序列自动接管。
- 退出调试档（回中档）后若已校准，同步带会自动回释放位置，注意挡块回位动作。

## 五、正常工作流程（一发）

### 1. 校准（每次上电一次）

右开关**中档**使能后自动开始（中断/失败：左开关**下→中**重来）。
日志：`start zero calibration` → `belt zero found` → `screw zero found` → `calibration done`。
长行程时耗时可达分钟级，属正常（按 mm/s 估算）。

### 2. 调射力（可选）

正常档右摇杆竖直。就绪后仍可调，**调完重新储能**。

### 3. 储能

左开关**下→中**：丝杆到射力位 → 同步带拉平台后移标定行程 → 限速回到释放位置。
完成：`charged, ready to fire` + 就绪音。耗时 ≈ 行程 ÷ 储能限速。

### 4. 发射

左开关**中→上**：舵机到释放角 → 弹射 → 回卡位 → 回待机（约 1.1 s）。

### 5. 连发

每发重复 2→3→4。发射后必须重新储能。打完右开关下档收工。

## 六、故障与恢复

| 日志 | 原因 | 处理 |
|---|---|---|
| `fault: belt calibration stall timeout` | 超时没顶到限位：方向反 / 离限位远 / 速度过慢 | 查 `DART_BELT_CALI_DIRECTION`；按 mm/s 重算限速与超时 |
| `fault: screw calibration stall timeout` | 丝杆同上 | 查 `DART_SCREW_CALI_DIRECTION` |
| `fault: belt/screw calibration backoff timeout` | 回撤卡住或目标不可达 | 查机械、行程宏是否按 ×64.76 填 |
| `fault: screw not in position before charge` | 储能前丝杆 2 s 没就位 | 查丝杆 / `DART_SCREW_POS_*` |
| `fault: belt stalled during charge` | **储能行程超滑台**或卡滞 | `DART_BELT_CHARGE_DEG` 按 mm 重标并调小 |
| `fault: charge timeout` | 拉不到目标 | 查行程宏、限速、机构 |
| `fault: retract timeout` | 回不到释放位置 | 查机械卡滞 |

### FAULT 恢复

1. 右开关**下档**，排除机械问题，确认平台是否仍锁住/已射；
2. 右开关**中档**；
3. 左开关**下→中**重新校准；
4. 通过后继续。

### 失能/失联行为

| 情况 | 行为 |
|---|---|
| 右开关下档 / 遥控器离线 | 电机断输出；**舵机保持当前角**（上电后正常态=卡位角，不会误放） |
| 校准中失能 | 零点作废，重新使能自动重校 |
| 储能中失能 | 再使能后先回撤挡块（`recovery retract done`）再储能 |
| 就绪后失能再使能 | 平台仍被锁，直接重新储能 |
| 发射中失能 | 舵机停当前角；再使能后按待机处理，必要时人工确认平台 |

## 八、正常流程速记（老手版）

1. 卸压；右开关下档上电。
2. 首次/装配：右开关**上档** → 按方向表点动验向、增量扫舵机、量 mm×64.76 填宏 → 烧录。
3. 右开关**中档**自动校准（长行程要等）→ 校准完成音。
4. 右摇杆竖直调射力 → 左开关下→中储能 → 中→上发射。
5. 连发重复 4；射力改动后重新储能。
6. `fault:` → 下档排查 → 中档 → 左开关下→中 重校准。
7. 急停永远是右开关下档；拨轮已弃用。

## 九、蜂鸣器提示对照

蜂鸣器在 TIM4_CH3。单次提示可被更高优先级声音打断；**持续指示**按节奏循环到条件解除。

### 单次提示

| 环节 | 听感 | 含义 |
|---|---|---|
| 使能成功 | 单短高滴 | 已使能 |
| 失能/急停 | 低双鸣 | 电机已断输出 |
| 进入调试档 | 短高滴 ×2 | 不自动校准，可点动 |
| 校准开始 | 渐高三连滴 Do-Mi-So | 顶限位流程启动 |
| 校准完成 | 上行双音 Mi-So | 进入待机，可储能 |
| 储能开始 | 单中鸣 | 开始拉拽 |
| 储能完成 | 上行 So-Do′ + SUCCESS | **就绪，可发射** |
| 发射瞬间 | 极短高音脉冲 | 舵机释放 |
| 发射完成 | 短滴 | 回待机 |
| 命令被忽略 | WARNING 双短 | 状态不满足 |

### 持续 / 警告

| 模式 | 听感 | 何时 |
|---|---|---|
| **WARNING** | A4 双短「嘀、嘀—」，停 0.6 s 循环 | 命令拒绝等 |
| **ERROR** | 高低「嘟—呜—」，停 0.6 s 循环 | **FAULT**：一次 + 持续到重校准 |
| **COMM_LOST** | 急促「嘀嘀嘀」三连，停 0.68 s 循环 | 遥控器离线，恢复后解除 |

### 首次上电“声音时间线”

1. 上电（右开关下档）：若遥控未连 → **COMM_LOST 循环**
2. 右开关上档：使能短滴 + 调试双滴
3. 校准：三连滴 →（长动作）→ **Mi-So**
4. 储能：单中鸣 → 就绪 **So-Do′**
5. 发射：高音短脉冲 → 完成短滴
6. **低双鸣 = 急停**；**ERROR 循环 = FAULT**

> 调试档只点动验方向时不应出现校准音。**一上电就开始顶限位 = 你拨的是中档不是上档，立刻急停。**
