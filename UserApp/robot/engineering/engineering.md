
# 工程机器人操作与控制说明书

## 1. 模式与状态说明

机器人包含多种工作模式和机械臂控制模式，以适应不同的赛场任务需求：

### 1.1 机器人主模式 (Robot Mode)
* **ROBOT_POWER_ON (上电模式)**: 初始待机状态。
* **ROBOT_EXCHANGE_MODE (兑换模式)**: 允许进行底盘升降、机械臂全向姿态调整，主要用于兑换站取弹或精细操作。
* **ROBOT_EMERGENCY_STOP (急停模式)**: 切断底盘、机械臂和图传云台动力的安全状态。

### 1.2 机械臂控制权模式 (Grab Control Mode)
*在**兑换模式**下，可切换以下三种机械臂控制权：*
* **键盘控制模式 (Keyboard)**: 完全由键盘接管机械臂的 5 个旋转关节和夹爪。
* **半自动控制模式 (Half-Auto)**: 结合鼠标左右键进行的半自动化抓取逻辑。
* **自定义控制器模式 (Custom)**: 读取外接的自定义控制器（如带有电位器的模拟机械臂）姿态映射到真实机械臂上。

## 2. 键盘与鼠标操作指南 (键鼠模式)

### 2.1 模式切换
| 操作按键 | 功能描述 | 备注 |
| :--- | :--- | :--- |
| **G 键** | 切换机器人主模式 | 在 **上电模式** 与 **兑换模式** 之间循环切换 |
| **F 键** | 切换机械臂控制模式 | 仅在 **兑换模式** 下有效，在 键盘/半自动/自定义 三种模式间循环切换 |

### 2.2 底盘控制 (全局生效)
| 操作按键 | 功能描述 | 备注 |
| :--- | :--- | :--- |
| **W / A / S / D** | 底盘平移控制 | W前进，S后退，A左移，D右移 |
| **R 键** | 切换底盘平移方向 | 按下后 WASD 控制的 X/Y 轴方向反转（通常用于倒车或视角翻转） |
| **Q / E** | 调节底盘升降高度 | 仅在 **兑换模式** 下有效 (调节 `lift_ratio`) |
| **Shift + Q / E** | 底盘旋转控制 | 仅在 **兑换模式** 且底盘处于降下状态时有效 |

### 2.3 机械臂与夹爪控制
*注意：以下大部分机械臂旋转控制仅在 **键盘控制模式** 及 **兑换模式** 下生效。*

| 操作按键 | 功能描述 | 生效条件 |
| :--- | :--- | :--- |
| **Shift + W / S** | 机械臂整体升降 | 键盘模式 / 自定义模式下均有效 |
| **Shift + Ctrl + Q / W** | 大 Yaw (基座旋转) | 仅纯键盘模式有效 |
| **Shift + Ctrl + E / R** | 大 Roll (肘部旋转) | 仅纯键盘模式有效 |
| **Shift + Ctrl + A / S** | 大 Pitch (肘部俯仰) | 仅纯键盘模式有效 |
| **Shift + Ctrl + D / F** | 小 Pitch (腕部俯仰) | 仅纯键盘模式有效 |
| **Shift + Ctrl + Z / X** | 小 Roll (腕部旋转) | 仅纯键盘模式有效 |
| **Shift + Ctrl + C** | 夹爪 开/合 切换 | 键盘模式下直接控制；自定义/半自动模式下自动映射开启状态 |

### 2.4 图传云台控制 (全局生效)
| 操作按键/鼠标 | 功能描述 |
| :--- | :--- |
| **鼠标 X 轴移动** | 图传云台 Yaw 轴（左右）旋转 |
| **鼠标 Y 轴移动** | 图传云台 Pitch 轴（上下）俯仰 |
| **B / V** | 键盘控制图传 Yaw 轴微调 |
| **Z / X** | 键盘控制图传 Pitch 轴微调 |

### 2.5 传感器标定与复位
| 操作按键 | 功能描述 |
| :--- | :--- |
| **Ctrl + Q** | 触发机械臂腕部 Roll 轴标定 |
| **Ctrl + E** | 触发机械臂腕部 Pitch 轴标定 |
| **Ctrl + V** | 触发图传云台 Pitch 轴双向堵转标定 |

## 3. 遥控器操作指南

遥控器主要用于底盘的移动、攀爬（如登岛）以及应急接管。

### 3.1 拨杆状态说明
* **右拨杆 (Right Switch)**：控制底盘大模式。
    * **上 (Up)**：进入**攀爬模式 (Climb)** 准备阶段。
    * **中 (Mid)**：进入**底盘跟随模式 (Follow)**。
    * **下 (Down)**：**底盘掉电 (Power Off)**。
* **左拨杆 (Left Switch)**：在右拨杆置于“上”时，控制具体的攀爬动作（带 0.3s 防误触消抖）。
    * **上 (Up)**：双侧伸出 (`CHASSIS_CLIMB_BOTH_EXTEND`)。
    * **中 (Mid)**：前侧收回 (`CHASSIS_CLIMB_FRONT_RETRACT`)。
    * **下 (Down)**：全部收回 (`CHASSIS_CLIMB_ALL_RETRACT`)。

### 3.2 摇杆与波轮控制
* **左摇杆 (上下)**：底盘 Y 轴移动（前进/后退）。
* **左摇杆 (左右)**：底盘 X 轴移动（左移/右移）。
* **左上方拨轮 (Dial)**：控制底盘的旋转目标角度 (`set_angle`)，在跟随模式或特定攀爬模式下生效。

## 4. 紧急情况处理

如果赛场上发生机械臂暴走、底盘失控等危及安全的紧急情况，可以通过以下两种方式触发**急停机制 (Emergency Stop)**：
1.  **遥控器急停**：同时将遥控器的 **左拨杆** 和 **右拨杆** 打到 **最底部 (Down)**。
2.  **断连保护**：当代码检测到遥控器离线 ( `!RemoteControlIsOnline()` ) 时，会自动触发急停。
    *急停后，底盘、机械臂、图传云台均会切断动力。*
