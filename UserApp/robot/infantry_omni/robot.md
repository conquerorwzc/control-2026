# infantry_omni

<p align='right'>SRM-Control 2026</p>

## 概述

infantry_omni 是一款使用全向轮底盘（麦轮解算）和双yaw串联云台的步兵机器人。

### 硬件配置

- **底盘**：4电机全向轮布局，使用麦轮解算
- **云台**：双yaw串联结构
  - 主yaw电机：GM6020
  - 副yaw电机：GM6020
  - pitch电机：J4310
- **发射器**：标准发射模块

### 双yaw串联云台结构

```
     yaw_master (GM6020)
          │
     yaw_slave (GM6020)
          │
     pitch (J4310)
```

**控制逻辑**：
- 主yaw电机控制整体旋转角度，使用IMU反馈
- 副yaw电机根据主yaw角度进行微调，实现叠加旋转
- 控制公式：`yaw_slave_ref = yaw_master_ref + yaw_slave_offset`

## 运行流程

运行流程可以很直观的从`RobotCMDTask()`中看出。

1. 首先通过消息订阅机制，获取其他应用的反馈信息
2. 使用`CalcOffsetAngle()`计算底盘和云台的offset angle（使得底盘始终获知当前的正方向）
3. 接着根据当前是通过键鼠or遥控器控制，调用对应的函数，将控制指令量化为具体的控制信息
4. 得到控制信息之后，先不急着发布，而是检测重要的模块和应用是否掉线或出现异常，以及遥控器是否进入紧急停止模式，如果以上情况发生，那么将所有的控制信息都置零，即让电机和其他执行单元保持静止。
5. 最后通过pubsub机制，把具体的控制信息发布到对应话题，让其他应用获取。若为双板，则将原本要推送给底盘的信息通过CANComm进行发送。

### 遥控器控制模式:

拨轮向下打到底进入紧急停止模式(后续改为关闭遥控器停止,利用daemon);拨轮向上打开启摩擦轮,超过一半开始发射(速度环,连发)

左侧开关:
- 上:键鼠控制
- 中:视觉控制(没有识别到目标的时候仍然可以使用遥控器控制云台)
- 下:遥控器控制

右侧开关:
- 上:弹舱开
- 中:底盘云台分离(底盘不旋转,全向移动)
- 下:底盘跟随云台

### 键鼠控制模式:

遥控器左侧开关拨到最上方,进入键鼠控制模式,此时不会响应遥控器遥感和拨轮的输入.

前后左右:WSAD

开关弹舱盖:R

小陀螺:Q

发射:鼠标左键

自瞄:鼠标右键

## 配置说明

### 底盘参数

在`robot_config.h`中配置：
- `wheel_base`：纵向轴距(前进后退方向)
- `track_width`：横向轮距(左右平移方向)
- `wheel_radius`：轮子半径
- `wheel_reduction_ratio`：电机减速比

### 云台参数

在`robot_config.h`中配置：
- `YAW_CHASSIS_ALIGN_ECD`：云台和底盘对齐指向相同方向时的电机编码器值
- `PITCH_HORIZON_ECD`：云台处于水平位置时编码器值
- `PITCH_MAX_ANGLE`：云台竖直方向最大角度
- `PITCH_MIN_ANGLE`：云台竖直方向最小角度
- `YAW_SLAVE_OFFSET`：副yaw相对于主yaw的偏移量

### 发射器参数

在`robot_config.h`中配置：
- `one_bullet_delta_angle`：发射一发弹丸拨盘转动的距离
- `friction_speed`：摩擦轮速度
- `target_speed`：目标弹速

## 注意事项

1. 首次使用前，请仔细检查`robot_config.h`中的所有参数配置
2. 确保电机CAN总线配置正确
3. 确保IMU安装方向正确
4. 副yaw偏移量需要根据实际机械结构调整
