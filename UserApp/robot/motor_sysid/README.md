# motor_sysid：遥控选档与 VOFA 空跑

本版本只生成一条腿两个主动关节的**参考角预览**，不注册或使能 DM/DJI 电机，不创建电机线程、不发送电机控制帧。不是可直接上车的扫频固件。H723 的现有 500 Hz 任务驱动 RobotTask；板级接线、UART/CAN 配置和 RTOS 文件未改。所有试验幅值、频率、参考中心、同/反相方向、时长和端口集中在 robot_config.h；预览值不代表实机标定。关节空间试验不需要再写五连杆求解。后续实车工作点/闭链校验优先复用队内几何函数，标定实际机构再接入。

## 拨杆

| 左拨杆 | 行为 |
|---|---|
| 下 | 软件急停/取消。仅表示停止参考激励，不是物理急停或驱动器硬件失能。 |
| 中 | 准备：右上慢速正弦往返，右中线性扫频，右下平滑平台。 |
| 上 | 使用准备时选择的模式。运行中切换右档不会直接跳到另一种激励。 |

每轮先在线左下→左中选档→左上运行。上电处于上档不启动；完成、中断、遥控离线后重新走这套流程。CH3 的状态值按 sysid_runner.h：0 等急停、1 急停、2 准备、3 起始、4 真运行（当前不可达）、5 完成、6 故障、7 空跑。CH4：0 无、1 慢速正弦、2 扫频、3 平台。慢速正弦不等于静摩擦起动试验或恒速三角波。

## VOFA+

默认使用本目标专用 USART1，机器人初始化时设置 **1,000,000 baud、8N1**（H7 原 USART1 是 115200，不改 Hardware）；遥控仍为 UART5，两者不能共线。VOFA+ 选择 **JustFloat**，按 CH0…CH23 录制，用户从 VOFA 导出 CSV 即可，不用运行 PC 串口脚本。每拍 24 个 float + 4 B 帧尾 = 100 B；500 Hz 合计 50 kB/s，含 8N1 约 500 kbit/s。总上限 1 Mbit/s，不是 1 MB/s。若上一帧 DMA 未结束，本拍不覆盖其缓冲、不阻塞控制，下一帧序号能看出缺拍；软件计算不等于实测链路无丢帧。

- CH0 序号（模 65536），CH1/2 板端微秒时戳高/低 16 位，CH3/4 状态/档位，CH5 标志位。
- CH6–21 按左前、左后、右前、右后，每组占四个字段：实测角、实测速度、限幅后力矩命令、反馈力矩。**本版这 16 路均为占位零，无测量含义**。
- CH22/23 为本轮前、后关节参考角（rad）。上电空跑先看这两条曲线和状态。
- CH5 bit6 是队内 RC 在线标志。bit0–3（新反馈）、bit5（驱动就绪）、bit7（允许真实执行）在本版均为 0。不得手工置位或把空跑 CSV 当作实测数据。

构建时显式选 `-DROBOT_TYPE=motor_sysid`；不改工程默认机器人。[上位机导出后的离线工具](../../../tools/hip_ident/README.md)检查字段、序号、固件时戳和有效性，原始 VOFA CSV 不改写。当前空跑文件被拒绝作为实测拟合输入是预期结果。

## 真实电机接入的边界

当前独立 target 没有已注册的电机句柄和既有发送任务。DM 模块的注册会主动使能；DMMotorStop 的语义是零力矩，并非硬件失能。不复制协议、不另写驱动或线程，不用直接发 CAN 绕过。实际出力之前须确定已有发送路径、核对实车 ID/零位/方向和限位、反馈与离线行为，单独验证人工急停。现阶段不提供用宏一键解锁出力的方式。髋起动/恒速摩擦、弹簧实测采集及轮电机**仅离地空载**测试尚未接通；不开展堵转或带载轮试验。
