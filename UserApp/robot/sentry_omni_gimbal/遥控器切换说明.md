# 遥控器切换说明

本项目支持两种遥控器：

1. **旧遥控器** (DJI标准遥控器) - 使用 `USE_REMOTE_CONTROL` 宏定义
2. **新VT13遥控器** - 使用 `USE_NEW_RC` 宏定义

## 如何切换遥控器类型

### 方法一：修改 CMakeLists.txt 文件

在 `UserApp/robot/sentry_omni_gimbal/robot.cmake` 文件中：

```cmake
# 如果需要使用新遥控器，取消下面一行的注释
# add_compile_definitions(USE_NEW_RC)

# 如果使用老遥控器，取消下面一行的注释  
# add_compile_definitions(USE_REMOTE_CONTROL)
```

**步骤：**
1. 打开 `robot.cmake` 文件
2. 根据需要使用的遥控器类型，取消对应行的注释
3. 注释掉另一个遥控器的定义
4. 重新编译项目

### 方法二：在IDE中设置编译定义

在你的IDE（如CLion、VSCode等）中设置预处理器定义：

- **使用旧遥控器**：添加 `USE_REMOTE_CONTROL` 到预处理器定义
- **使用新遥控器**：添加 `USE_NEW_RC` 到预处理器定义

## 两种遥控器的区别

### 旧遥控器 (USE_REMOTE_CONTROL)
- 使用串口3 (huart3) 接收数据
- 数据结构：`RC_ctrl_t`
- 拨杆值：UP=1, MID=3, DOWN=2
- 支持传统DJT遥控器的所有功能

### 新VT13遥控器 (USE_NEW_RC)  
- 使用串口6 (huart6) 接收数据
- 数据结构：`VT13_RC_t`
- 拨杆值：UP=1, MID=3, DOWN=2 (mode_switch字段)
- 支持鼠标键盘控制
- 更高的数据传输速率

## 紧急停止逻辑差异

### 旧遥控器紧急停止
- 两个拨杆都在下档时触发
- 遥控器断连时触发

### 新VT13遥控器紧急停止
- 右拨杆在下档时触发
- 暂停键按下时触发
- 扳机键按下时发射系统失能

## 注意事项

1. **只能启用一种遥控器**：同时定义两个宏会导致编译错误
2. **串口配置**：确保硬件连接正确，旧遥控器接huart3，新遥控器接huart6
3. **重新编译**：每次切换遥控器类型后都需要重新编译整个项目
4. **测试验证**：切换后建议进行充分的功能测试

## 故障排除

如果遇到问题：

1. 检查是否只定义了一个遥控器宏
2. 确认串口连接正确
3. 查看串口配置是否匹配
4. 检查遥控器电源和连接状态
5. 查看日志输出确认遥控器是否正常初始化
