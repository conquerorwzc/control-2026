# ACE 显式 k 缩放五连杆轮腿实机测试清单

> 本清单服务于 `wheel_legged_double_closed_loop_lqr` 的 MATLAB 模型与 STM32 固件对齐。
> 当前固件已经具备四输入 LQR 输出路径；清单用于确认状态、方向、执行器和工作点一致后，再逐步放大真实出力。
>
> **安全红线：** 未明确允许前不烧录。关节电机使能、PID、力矩或电流输出存在时，严禁通过断点、暂停、单步等方式停止 MCU。四输入闭环的唯一人工使能是遥控器右拨杆中档；出现任何异常先把右拨杆拨到上或下档，等待六台电机 Stop 后再检查变量。

### 4.4 腿长速度 right_leg_length_dot 的定义与验证

right_leg_length_dot 是真实虚拟腿长度 l=|OJ| 的瞬时变化率，不是轮轴的 y 速度，也不是用两帧腿长直接相减得到的数。其代码定义为：

$$
\dot l_R=
J_{l,R}(0,0)\dot\phi_1+
J_{l,R}(0,1)\dot\phi_2
$$

其中真实末端 J 的第一行雅可比为：

$$
J_{l,R}=
\frac{\partial l_R}{\partial[\phi_1,\phi_2]}
$$

右前关节对应 φ1，右后关节对应 φ2。每个主动轴角速度由对应电机反馈速度乘链传动方向和传动比得到：

$$
\dot\phi_i=
s_i g_i\dot q_{m,i}
$$

因此 right_leg_length_dot 的单位是 m/s。它会直接受电机速度量化噪声、CAN 反馈噪声、链传动方向和 Jacobian 接近奇异时放大效应影响，静止时不一定每一帧严格等于 0。

- [ ] 静止手松后，right_leg_length_dot 围绕 0 小幅波动，不持续单侧偏置。
- [ ] 低速手动伸右腿时，right_leg_length_dot > 0；低速缩腿时小于 0。
- [ ] 同时记录 phi[0]、phi[1]、两台电机 measure.velocity 与 real_leg_jacobian 第一行，确认公式逐项一致。
- [ ] 用低速时间窗的 Δright_leg_length/Δt 与 right_leg_length_dot 的平均值比较；不要用单个 1 ms 样本作结论。
- [ ] 若方向相反，先检查右前/后 φ 槽位、链传动 direction、零位和 real_leg_jacobian，不得在 right_leg_length_dot 后直接手动取负。

### 6.4 腿长控制与四输入输出前检查

腿长 PID 不使用关节角位置环。它从 FK 读取当前 l 与 l_dot，产生虚拟轴向力 F，再复用已验证的 VMC：

$$
F_{PI}=\operatorname{PIDCalculate}(l,l_{ref})
$$

$$
F=\operatorname{limit}(F_{PI}-K_{d,leg}\dot l, -\mathrm{MaxOut}, +\mathrm{MaxOut})
$$

左右腿 PID 参数只在 `wheel_legged_demo_27/robot_config.h` 中配置。当前配置为 `force_pid.Kp=500 N/m`、`force_pid.Ki=0`、`force_pid.Kd=0`、`velocity_damping_kd=5 N*s/m`、`force_pid.MaxOut=20 N`，且只允许 0.03 m 至 0.23 m 的 FK 腿长进入力控。通用 PID 的 `force_pid.Kd` 必须保持 0；D 项只来自真实 Jacobian 的 l_dot，不使用两帧腿长差分。F 限幅与每台 J4310 的 ±8 N*m 电机轴调试限幅是两层不同保护，必须同时保留。0.03 m 和 0.23 m 都只是不立即判错的数值边界，仍必须避开机构学奇异区。

## 7. LQR 计算与输出仲裁验收

LQR 每周期计算下式，结果保存在 `robot->chassis->lqr`，并在状态有效时发布到两腿 VMC 的 Tp 和轮毂输出仲裁器。MATLAB 状态中的 `s` 是左右轮端平均滚动里程计，不是髋点 O 的实际纵向位移；髋点量只用于诊断对比。重新生成 K 后才能使用：

$$
\mathbf u=\mathbf u_0-\mathbf K(\mathbf x-\mathbf x_{ref})
$$

其中输入顺序固定为 `[Tp_R, Tp_L, Tw_R, Tw_L]`。LQR 本身不调用电机接口；但 `ChassisTask()` 会把结果发布到 VMC 和唯一输出仲裁器。只有在 `CHASSIS_POWER_OFF` 下，仲裁器才会强制六台电机 Stop、所有实际力矩为 0。

- [x] 主机端已验证：x=x_ref 时 output=u0；单状态偏差满足 output=u0-K*error；非法状态、NaN 或未采集零点时 valid=0 且四路 output 清零。当前 K 固定为 0.170 m，不按实测腿长调度。
- [x] H7 Debug 已完成编译，未烧录。
- [ ] 经明确许可烧录后，保持 `CHASSIS_POWER_OFF`，确认未满足完整状态时 `lqr.valid=0`、四路 output=0。
- [ ] 等待 `chassis_state.origin_captured=1`；确认左右腿长均接近设计点 0.170 m，且 `chassis_state.valid_mask` 包含左右轮、IMU、左右腿和纯轮式里程计有效位。
- [ ] 确认 `lqr.valid=1`，并逐项核对 `lqr.state_error[i] = chassis_state.state_vector[i] - lqr.state_reference[i]`。
- [ ] 任取一行，例如 Tp_R，手算 `lqr.output[0] = lqr.trim_input[0] - sum(lqr.gain[0][i] * lqr.state_error[i])`，与变量窗口一致。
- [ ] 改变一个小状态量后，确认 K、x_ref、u0 不会被实测腿长静默改写；当前固定 K 只允许在 0.170 m 附近观察，不得据此外推到大幅伸缩姿态。

### 7.1 自动腿长准备阶段

右拨杆中档后不再立即接入 Tp/Tw。底盘先进入 `WHEEL_LEGGED_BALANCE_PHASE_LEG_PREPARE`，此时只允许腿长 PID 的 F 经过 VMC，左右 `pitch_torque_command` 和轮毂 `motor_torque_output` 必须为 0。腿长阶段只有轴向力，不能主动把腿摆角和机身 Pitch 调到零，因此腿角和 Pitch 只作为手扶启动安全范围。以下条件累计满足约 100 ms 后，状态自动切换到 `WHEEL_LEGGED_BALANCE_PHASE_ACTIVE`：

```text
abs(left_length  - 0.170) <= 0.015 m
abs(right_length - 0.170) <= 0.015 m
abs(left_length_dot)      <= 0.15 m/s
abs(right_length_dot)     <= 0.15 m/s
abs(theta_leg_left/right) <= 0.65 rad
abs(theta_body)           <= 0.25 rad
```

- [ ] 右拨杆中档后先看到 `balance_phase=LEG_PREPARE`；观察 `balance_prepare_block_reason`，为 0 时 `balance_prepare_count` 增加。
- [ ] PREPARE 阶段左右轮 `torque_command`、`motor_torque_output` 为 0，左右腿 `pitch_torque_command` 为 0，但有效的腿长 F 可以驱动 J4310 接近 0.170 m。
- [ ] `balance_prepare_left/right_length_error` 分别等于当前腿长减 0.170 m，绝对值应不超过 0.015 m。
- [ ] 除单周期腿速毛刺外，任一准备条件不满足时计数清零；仅腿速短暂超限时计数每周期减 1，避免一次毛刺丢失全部稳定时间。
- [ ] 累计满足 100 个周期后看到 `balance_phase=ACTIVE`，此后才允许小量 Tp/Tw。
- [ ] 右拨杆离开中档后 `balance_phase=POWER_OFF`、计数清零且六台电机 Stop；再次进入中档必须重新准备。

`balance_prepare_block_reason` 是可叠加位掩码：

| 数值 | 含义 |
| ---: | --- |
| 1 | 遥控器未请求 `CHASSIS_ON` |
| 2 | 十维状态来源不完整 |
| 4 | 准备参数非法 |
| 8 / 16 | 左 / 右腿长度未进入目标窗口 |
| 32 / 64 | 左 / 右腿长度速度过大 |
| 128 / 256 | 左 / 右腿角超出手扶启动范围 |
| 512 | 机身 Pitch 超出手扶启动范围 |

多个条件同时失败时数值相加。例如 `72=64+8` 表示右腿长度速度过大且左腿长度未进入目标窗口。
