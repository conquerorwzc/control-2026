# 双闭环轮腿实机测试清单

> 本清单服务于 `wheel_legged_double_closed_loop_lqr` 的 MATLAB 模型与 STM32 固件对齐。
> 目标不是立刻运行 LQR，而是逐项确认状态、方向、执行器和工作点的物理含义一致。
>
> **安全红线：** 未明确允许前不烧录。关节电机使能、PID、力矩或电流输出存在时，严禁通过断点、暂停、单步等方式停止 MCU。VMC 试验必须单腿悬空、手扶机构、远离机械限位；先清零 `torque_test_enable`，再修改任何 F 或 Tp。

## 1. 当前能力边界

| 项目 | 当前状态 | 说明 |
| --- | --- | --- |
| 双闭环 FK / Jacobian | 已接入 | 由四个关节反馈计算轮轴 P、虚拟腿长和虚拟腿角。 |
| 十维状态 | 已接入 | `s` 是髋点 O 的纵向里程计，包含轮滚动、腿摆和腿长变化项。 |
| 关节 VMC | 可做小力矩测试 | F、Tp 经 Jacobian 映射至两个 J4310；单台电机轴限幅为 ±2 N·m。 |

| LQR K | 已离线导出 | 仅为 MATLAB 生成常量，尚未接入 MCU 控制链。 |

## 4. 十维状态与传感器方向确认

建议观察路径：

```text
robot->chassis->chassis_state
```

### 4.1 状态有效性

- [ ] `origin_captured = 1`。
- [ ] `valid_mask` 包含左右轮、IMU、左右腿和髋点里程计有效位。
- [ ] 任一关节反馈、轮反馈或 IMU 失效时，相应有效位清零。
- [ ] 失效时本周期 `s`、`s_dot` 不伪装为完整有效数据。

### 4.2 IMU 方向

MATLAB 约定：机身前端向下时 `theta_b` 为正；车头向左转时 `phi` 为正。

- [ ] 缓慢使机身前端向下，`theta_body` 增大为正。
- [ ] 缓慢使机身前端向上，`theta_body` 减小为负。
- [ ] 缓慢使车头向左，`phi` 增大为正。
- [ ] `theta_body_dot`、`phi_dot` 的变化方向与手动动作一致。

实测记录：

| 动作 | `theta_body` / `phi` 实测符号 | MATLAB 期望 | 是否一致 |
| --- | --- | --- | --- |
| 前端向下 |  | `theta_body > 0` |  |
| 前端向上 |  | `theta_body < 0` |  |
| 车头左转 |  | `phi > 0` |  |

### 4.3 轮向与髋点里程计

- [ ] 手推整车前进时，左、右 `wheel_speed` 均为正。
- [ ] 手推整车前进时，`s_dot` 为正。
- [ ] 推一段已知距离后，`s` 的数值与实际前进距离量级一致。
- [ ] 轮子不转、腿从后向前摆时，对应侧 `hip_odometry_s_dot` 为正。
- [ ] 轮子不转、腿长变化时，`hip_odometry_s_dot` 的方向符合实际髋点运动。
- [ ] 左右轮 `direction` 已通过手推试验确认，而非仅使用默认值。

## 6. 单腿 VMC 小力矩测试

仅在第 3 至第 5 节通过后进行。每次只测试一条腿、一个广义力分量。

### 6.1 使能前检查

- [ ] 遥控器使底盘处于 `CHASSIS_POWER_OFF` 时，两个 `*_motor_torque_output` 均为 0。
- [ ] 使能关节但 `torque_test_enable = 0` 时，两个 `*_motor_torque_output` 仍为 0。
- [ ] 当前腿 `vmc.valid = 1`。
- [ ] `front_motor_torque`、`rear_motor_torque` 为有限数值，且远离 ±2 N·m 限幅。

### 6.2 F 方向

设置一条腿：

```text
force_command = 小正值
pitch_torque_command = 0
torque_test_enable = 1
```

- [ ] 正 F 的伸缩趋势符合定义。
- [ ] 负 F 的伸缩趋势与正 F 相反。
- [ ] 关闭 `torque_test_enable` 后，两个输出力矩立即回到 0。

实测记录：

| 腿 | F 正值趋势 | F 负值趋势 | 最大电机轴输出 N·m | 结论 |
| --- | --- | --- | ---: | --- |
| 左腿 |  |  |  |  |
| 右腿 |  |  |  |  |

### 6.3 Tp 方向

设置一条腿：

```text
force_command = 0
pitch_torque_command = 小正值
torque_test_enable = 1
```

- [ ] 正 Tp 使该腿的 `virtual_leg_theta` 朝正方向变化。
- [ ] 负 Tp 使该腿的 `virtual_leg_theta` 朝负方向变化。
- [ ] 左右腿的正 Tp 都符合各自虚拟腿角正方向。
- [ ] 没有在 VMC 之后额外手动对 Tp 取负。

> MATLAB 模型正 Tp 与当前 VMC 正 Tp 的定义相反，MATLAB 已通过 `input_sign = [-1, -1, 1, 1]` 处理前两项。实测通过后，MCU 接 LQR 时不得再额外翻转 Tp。
